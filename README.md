# 礼账 Android App

## 项目介绍

礼账是一款面向家庭与个人的人情礼金记录应用，用于管理联系人、收礼与送礼记录、日期提醒、统计以及本地数据备份。应用坚持本地优先，联系人和礼金数据保存在设备 Room 数据库中。

当前产品不包含 OCR、图片上传或云端识别功能。原有 OCR 实验因真实手写礼簿准确率不足已完整下线，记账入口统一使用可校验的手动录入流程。

## 本地通讯录导入 V1

联系人页面右下角“＋”展开后选择“通讯录导入”：仅在用户主动进入后申请 `READ_CONTACTS`，默认选中新联系人；标准化同号禁止导入，同名不同号标记“同名联系人”且默认不选，可手动选择。支持搜索、全选及脱敏预览。提交时在 Room 事务内复查，只新建、不覆盖或合并，返回后展示成功、已存在跳过、可能重复未选择三项统计并刷新列表。

通讯录只在本机内存中处理，不联网、不缓存原始通讯录、不申请 `WRITE_CONTACTS`。系统自动备份仍禁用；主动本地备份包含已导入的普通联系人。未修改数据库结构、版本或备份格式。详见 [通讯录导入设计](docs/通讯录导入设计.md)。

## 联系人批量管理 V1

联系人顶部“管理”进入多选，按联系人 ID 保留选择；搜索和排序不会清空已选项，“全选”仅追加当前搜索结果，“取消全选”清空全部选择。返回键先退出管理模式。删除前展示实际联系人数量、有关联往来的联系人数量及礼金记录总数；涉及礼金需额外勾选级联删除确认。正式提交在 Room 事务内复查，数量变化则不删除并要求重新确认，成功后自动退出管理、刷新列表并显示实际删除数量。

无自动删除、无新增字段或数据库迁移。详细规则与测试见 [联系人批量管理](docs/联系人批量管理.md)。

## 全局 UI 重构 V1（0.3.0）

返修后的全局视觉采用低饱和浅蓝 → 暖白 → 浅橘渐变与单层半透明玻璃组件，深色模式使用灰蓝 → 暖灰褐渐变。底部导航为浮动圆角栏，按钮、筛选、卡片和弹窗共享样式参数。联系人导入大卡片已移除，右下角菜单提供“通讯录导入”和“手动添加”；再次点击、外部点击或返回键会收起，管理模式隐藏菜单。联系人按稳定 ID 懒加载，大字体下净往来移到姓名下方，底部预留浮层空间。

猫咪插画统一使用具有真实 Alpha 通道的 PNG，避免深色页面出现白色底块。提醒日期仍支持当天、提前 1 / 3 / 7 天，选项改为统一弹窗内的单选行。业务规则、Room 结构、备份格式与导航状态策略保持不变。

首页已移除右下角记账 FAB，记账入口使用底部“记一笔”。快捷入口统一蓝橘双色；表单字段、提醒设置与联系人/设置列表清理实体内层底色。底部导航和联系人展开菜单保留已验收交互。返修原因和验证记录见 [UI 返修说明](docs/UI返修V1.md)。

初版设计参数、资产来源与验收记录见 [UI 重构说明](docs/UI重构V1.md)。当前版本为 `versionName = 0.9.12`、`versionCode = 22`。

## 悬浮毛玻璃（0.8.0）

底部导航、记一笔保存栏、联系人「+」与展开菜单统一使用 Haze 1.6.4 的背景采样和高斯模糊。模糊半径 20dp，浅色 tint 0.18、深色 0.32、边框 0.12；保留导航/保存栏 30dp 圆角与 6dp 外围阴影。只模糊浮层后方的页面，文字和图标保持锐利。联系人按钮改为无 Material Surface 的 56dp 容器，主页搜索/通知按钮组间距 10dp。

Compose BOM 保持 2025.06.01。API 26–30 使用低透明度玻璃回退，API 31+ 使用真正的 backdrop blur；预览截图渲染器不支持 GPU 模糊，显式使用回退，真实效果由设备像素测试验收。普通卡片、输入框与弹窗保持原有玻璃样式。保存栏仍为 76dp Overlay，保留键盘避让、450ms 返回和重复提交保护。Room 2、MIGRATION_1_2、备份格式 3 不变。

实现、测试与设备限制详见 [v0.8.0 毛玻璃验收](docs/毛玻璃0.8.0.md)。

## 多语言（0.9.0）

“我的”页面提供语言入口，支持跟随系统、简体中文、繁體中文、English、日本語、한국어、Español、Français。使用 Android/AppCompat 官方应用语言与持久化机制，沿用玻璃弹窗、现有导航和页面设计。七套资源覆盖页面、提示、无障碍描述和通知，并处理复数、日期及数字格式；金额始终为人民币，不增加多币种。

简体中文资源仍只维护一份，构建时生成显式中文限定资源，保证英文系统下切换简体中文正确生效；繁体中文独立维护，识别 `zh-Hant` 及台湾、香港、澳门地区标签。Room 结构、现有数据和备份格式保持兼容。导出文案随语言变化，数值与日期保持兼容，建议文件名统一使用 Lizhang 品牌前缀。原始实现见 [v0.9.0 多语言](docs/多语言0.9.0.md)，新增语言与联系人顶部插图调整见 [多语言扩展与联系人页调整](docs/多语言扩展与联系人页调整.md)。

## 首次使用引导（0.9.3）

全新安装提供可跳过的三页引导，复用现有猫咪、渐变与玻璃组件，支持中英日韩、浅色、深色及跟随系统。完成或跳过后不再自动出现；“我的 → 使用引导”可重新查看，完成后回到设置页，不修改首次完成状态。已有安装按安装更新时间、旧数据库或设置文件痕迹集中判断，升级不强制展示首次教程。

空首页和空联系人页分别提供一次轻量操作提示，点击空白、关闭或开始操作即可消失。通讯录仅在主动导入时请求权限；Android 13 及以上的通知权限仅在主动启用提醒时请求，先说明用途，点击“继续”才打开系统权限对话框。拒绝后保留正常使用，永久拒绝提供系统设置入口。引导本身不读取通讯录、不初始化提醒、不联网。

引导状态沿用 SharedPreferences，不修改 Room 数据库版本 2、现有表结构或礼金备份格式 3；系统自动备份仍禁用。实现、测试、升级兼容和文件清单见 [v0.9.3 首次使用引导](docs/首次使用引导0.9.3.md)。

## 连续功能引导（0.9.4）

全新用户完成或跳过三页首次引导后，在首页看到“记一笔 → 联系人 → 提醒 → 我的”四步玻璃气泡。可点击下一步留在首页查看，也可正常打开对应功能：保存下一步，离开首页暂停，自己回首页后继续。任一步跳过会永久结束；不自动导航、不遮黑屏幕、不阻断原入口，也不触发权限申请。

统一 `FeatureGuideStep` 沿用同一份 Onboarding 偏好保存，支持旋转、语言重建和进程重启恢复。四个目标从真实 Compose 布局报告坐标，气泡避让系统安全区、实际底栏和屏幕边缘；中英日韩、深浅色及大字体均有测试。0.9.3 已完成首次引导的升级用户不自动展示四步；未完成用户仍在三页结束后开始。首页与联系人旧独立提示由四步流程替代，旧 key 保留。“我的 → 使用引导”只重看原三页，不重置四步进度。实现和验证见 [v0.9.4 首次功能引导](docs/首次使用引导0.9.4.md)。

```text
Room / SharedPreferences / Android 系统能力
```

- `ui`：Compose 页面、通用组件、导航、主题和页面状态。
- `domain`：业务模型、Repository 接口、备份、导出和提醒规则。
- `data`：Room、Repository 实现、本地偏好和系统提醒实现。
- `core`：日期、金额、常量和扩展函数。
- `data/di/AppContainer`：应用级依赖组合根，为未来接入 Hilt 保留清晰边界。

业务逻辑不放在 Composable 中；UI 只观察 `StateFlow` 并发送用户意图。

### GiftRecord（礼金记录）

| 字段 | 说明 |
| --- | --- |
| `id` | 自增主键 |
| `contactId` | 联系人外键，联系人删除时级联删除 |

| `eventType` | 婚礼、满月、生日、乔迁、节日、其他 |

| `direction` | `RECEIVED` 或 `GIVEN` |
| `notes` | 可选备注 |
| `createdTime` | 创建时间戳 |

当前数据库版本为 2，注册非破坏性 1→2 迁移，为礼金记录增加可空的自定义事件名称，旧数据完整保留。备份恢复使用独立领域格式，不直接复制 SQLite 文件；普通备份格式已升级为版本 3，记录来源数据库版本及自定义事件名称，并兼容读取版本 1 和 2。普通备份使用 SHA-256 完整性校验，可选密码备份使用 PBKDF2-HMAC-SHA256 与 AES-256-GCM 加密认证，并在单个 Room 事务中恢复数据。

## 已完成功能

- 首页支持下拉选择统计年份，并按所选年份重新计算收礼、送礼与净往来汇总；候选年份根据设备当前年份和最早账本记录动态生成，不写死年份且不会超过现实年份。
- 手动新增、查看、编辑和删除礼金记录；录入页采用独立任务流，表单可滚动，保存按钮固定在系统安全区上方并随软键盘避让；存在未保存修改时，返回操作会先居中确认是否放弃；日期选择与保存校验均禁止晚于真实当天。
- 联系人搜索、中文姓名排序、新增、编辑、详情与删除；“最近往来”根据最后一笔礼金日期真实倒序；新增入口采用与首页一致的圆形主色悬浮按钮；从联系人详情新增往来会自动预选当前联系人，编辑联系人后未保存返回会先居中确认。
- 收礼记录、送礼记录、日历视图、全局搜索和年度统计；搜索结果与联系人选择器使用可滚动惰性列表，适配大量数据。
- 年度统计覆盖月度、事件和联系人维度，事件统计分别展示收礼与送礼金额。
- 独立日期提醒，默认一次、可选每年重复，支持新增、编辑、停用、删除、通知权限、当天或提前 1 / 3 / 7 天及统一提醒时间；通知进入提醒列表，不与记一笔绑定。
- CSV 与标准 XLSX 导出。
- `.lizhangbackup` 本地备份、校验、确认和事务恢复；支持普通备份格式 v1/v2/v3 兼容、来源数据库版本提示、普通或密码加密备份，密码不会持久化保存。
- Material 3 浅色/深色配色。
- 主题设置支持“跟随系统、浅色模式、深色模式”，选择结果持久保存并立即生效。
- 大字体与深色模式下的固定浅色插画卡、快捷图标、表单边界和选中标签采用独立高对比前景色，并由对比度单元测试与截图基准保护。
- 字体说明支持跳转 Android 系统显示设置；关于页说明产品范围和版本。
- 隐私说明明确本地存储、无联网权限、通知权限、导出备份和数据删除规则。
- 禁用 Android 系统自动备份和换机数据迁移，联系人与礼金数据只通过用户主动选择的本地备份文件迁移。
- 浮动半透明底部导航、奶白色背景、统一姓氏头像和中文居中反馈。
- 首页、联系人、礼金详情、收送记录、日历、提醒、搜索和统计的加载失败状态均提供可实际重新订阅数据的重试操作。
