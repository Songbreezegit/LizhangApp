# 礼账 Android App

## 项目介绍

礼账是一款面向家庭与个人的人情礼金记录应用，用于管理联系人、收礼与送礼记录、日期提醒、统计以及本地数据备份。应用坚持本地优先，联系人和礼金数据保存在设备 Room 数据库中。

当前产品不包含 OCR、图片上传或云端识别功能。原有 OCR 实验因真实手写礼簿准确率不足已完整下线，记账入口统一使用可校验的手动录入流程。

## 本地通讯录导入 V1

联系人页面右下角“＋”展开后选择“通讯录导入”：仅在用户主动进入后申请 `READ_CONTACTS`，默认选中新联系人；标准化同号禁止导入，同名不同号标记“同名联系人”且默认不选，可手动选择。支持搜索、全选及脱敏预览。提交时在 Room 事务内复查，只新建、不覆盖或合并，返回后展示成功、已存在跳过、可能重复未选择三项统计并刷新列表。

通讯录只在本机内存中处理，不联网、不缓存原始通讯录、不申请 `WRITE_CONTACTS`。系统自动备份仍禁用；主动本地备份包含已导入的普通联系人。未修改数据库结构、版本或备份格式。详见 [通讯录导入设计](docs/通讯录导入设计.md)。

## 联系人批量管理 V1

联系人顶部“管理”进入多选，按联系人 ID 保留选择；搜索和排序不会清空已选项，“全选”仅追加当前搜索结果，“取消全选”清空全部选择。返回键先退出管理模式。删除前展示实际联系人数量、有关联往来的联系人数量及礼金记录总数；涉及礼金需额外勾选级联删除确认。正式提交在 Room 事务内复查，数量变化则不删除并要求重新确认，成功后自动退出管理、刷新列表并显示实际删除数量。

无自动删除、无新增字段或数据库迁移。详细规则与测试见 [联系人批量管理](docs/联系人批量管理.md)。

## 全局 UI 重构 V1（0.3.0）

返修后的全局视觉采用低饱和浅蓝 → 暖白 → 浅橘渐变与单层半透明玻璃组件，深色模式使用灰蓝 → 暖灰褐渐变。底部导航为浮动圆角栏，按钮、筛选、卡片和弹窗共享样式参数。联系人导入大卡片已移除，右下角菜单提供“通讯录导入”和“手动添加”；再次点击、外部点击或返回键会收起，管理模式隐藏菜单。联系人按稳定 ID 懒加载，大字体下净往来移到姓名下方，底部预留浮层空间。

## 架构设计

项目采用单 `app` 模块、按职责分包的 Clean MVVM 结构：

```text
Compose UI
    ↓
ViewModel
    ↓
domain.repository
    ↑
data.repository / data.preferences
    ↓
Room / SharedPreferences / Android 系统能力
```

- `ui`：Compose 页面、通用组件、导航、主题和页面状态。
- `domain`：业务模型、Repository 接口、备份、导出和提醒规则。
- `data`：Room、Repository 实现、本地偏好和系统提醒实现。
- `core`：日期、金额、常量和扩展函数。
- `data/di/AppContainer`：应用级依赖组合根，为未来接入 Hilt 保留清晰边界。

业务逻辑不放在 Composable 中；UI 只观察 `StateFlow` 并发送用户意图。

## 数据库设计

### Contact（联系人）

| 字段 | 说明 |
| --- | --- |
| `id` | 自增主键 |
| `name` | 姓名，已建立索引 |
| `phone` | 可选手机号，已建立索引 |
| `relationship` | 可选关系 |
| `notes` | 可选备注 |
| `createdTime` | 创建时间戳 |

### GiftRecord（礼金记录）

| 字段 | 说明 |
| --- | --- |
| `id` | 自增主键 |
| `contactId` | 联系人外键，联系人删除时级联删除 |
| `amountInCents` | 金额，单位为分 |
| `eventType` | 婚礼、满月、生日、乔迁、节日、其他 |
| `eventDate` | 事件日期时间戳 |
| `direction` | `RECEIVED` 或 `GIVEN` |
| `notes` | 可选备注 |
| `createdTime` | 创建时间戳 |

当前数据库版本为 1。备份恢复使用独立领域格式，不直接复制 SQLite 文件；普通备份格式已升级为版本 2，记录来源数据库版本，并兼容读取版本 1。普通备份使用 SHA-256 完整性校验，可选密码备份使用 PBKDF2-HMAC-SHA256 与 AES-256-GCM 加密认证，并在单个 Room 事务中恢复数据。

## 已完成功能

- 首页支持下拉选择统计年份，并按所选年份重新计算收礼、送礼与净往来汇总；候选年份根据设备当前年份和最早账本记录动态生成，不写死年份且不会超过现实年份。
- 手动新增、查看、编辑和删除礼金记录；录入页采用独立任务流，表单可滚动，保存按钮固定在系统安全区上方并随软键盘避让；存在未保存修改时，返回操作会先居中确认是否放弃；日期选择与保存校验均禁止晚于真实当天。
- 联系人搜索、中文姓名排序、新增、编辑、详情与删除；“最近往来”根据最后一笔礼金日期真实倒序；新增入口采用与首页一致的圆形主色悬浮按钮；从联系人详情新增往来会自动预选当前联系人，编辑联系人后未保存返回会先居中确认。
- 收礼记录、送礼记录、日历视图、全局搜索和年度统计；搜索结果与联系人选择器使用可滚动惰性列表，适配大量数据。
- 年度统计覆盖月度、事件和联系人维度，事件统计分别展示收礼与送礼金额。
- 未来 30 天年度日期提醒，支持通知权限、当天、提前 1 天、提前 3 天、提前 7 天及提醒时间设置；点击系统通知可直接进入对应礼金记录，记录已删除时安全回到首页并居中提示。
- CSV 与标准 XLSX 导出。
- `.lizhangbackup` 本地备份、校验、确认和事务恢复；支持普通备份格式 v1/v2 兼容、来源数据库版本提示、普通或密码加密备份，密码不会持久化保存。
- Material 3 浅色/深色配色。
- 主题设置支持“跟随系统、浅色模式、深色模式”，选择结果持久保存并立即生效。
- 大字体与深色模式下的固定浅色插画卡、快捷图标、表单边界和选中标签采用独立高对比前景色，并由对比度单元测试与截图基准保护。
- 字体说明支持跳转 Android 系统显示设置；关于页说明产品范围和版本。
- 隐私说明明确本地存储、无联网权限、通知权限、导出备份和数据删除规则。
- 禁用 Android 系统自动备份和换机数据迁移，联系人与礼金数据只通过用户主动选择的本地备份文件迁移。
- 浮动半透明底部导航、奶白色背景、统一姓氏头像和中文居中反馈。
- 首页、联系人、礼金详情、收送记录、日历、提醒、搜索和统计的加载失败状态均提供可实际重新订阅数据的重试操作。

## 页面与导航

底部主导航固定为：

1. 首页
2. 联系人
3. 记一笔
4. 我的

“记一笔”和首页悬浮按钮现在均直接进入手动新增页面。进入录入任务后暂时隐藏主导航，用户通过保存或返回结束任务，避免底部导航遮挡保存按钮或造成误切换。业务子页面包括联系人详情、礼金详情与编辑、收礼记录、送礼记录、日历、提醒、统计、搜索、字体与显示、关于礼账和隐私说明。

## 运行方式

1. 在 Android Studio 选择 **Open**。
2. 打开 `D:\AndroidProjects\LizhangApp`。
3. 使用 Android Studio 自带 JDK 17。
4. 等待 Gradle Sync 完成。
5. 选择 Pixel 9 模拟器或物理设备运行 `app`。

命令行构建：

```powershell
.\gradlew.bat :app:assembleDebug
```

Debug APK 输出：

```text
app/build/outputs/apk/debug/app-debug.apk
```
