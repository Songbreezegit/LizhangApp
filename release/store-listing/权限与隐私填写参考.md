# 权限与隐私填写参考（待本人审定）

来源为现有 Manifest、直接运行时依赖声明、相关实现及已批准的离线隐私政策。本文是商店填写的事实参考，不替代已批准正文，不直接给出各渠道“收集/共享/上传/敏感信息”等问卷选项的最终结论，也未替本人勾选或提交。

## 权限用途候选

| 权限 | 可供本人审定的用途说明 | 触发与拒绝后的影响 |
| --- | --- | --- |
| `android.permission.READ_CONTACTS` | 用户主动进入手机联系人导入并授权后，读取有电话号码的联系人姓名、完整号码及系统标识，在本机搜索、预览和去重；确认后仅把所选姓名、号码导入礼账 | 不是启动应用即读取。拒绝后仍可手动添加联系人及记账；不修改、删除系统通讯录，不把系统联系人标识保存为礼账联系人字段 |
| `android.permission.POST_NOTIFICATIONS` | 在需要此权限的 Android 版本上，经用户授权后，用于显示本人创建的本地日期提醒通知 | 通知包含提醒标题、日期等内容，可能出现在通知栏或锁屏。拒绝后不影响记账、联系人及导出备份 |
| `android.permission.RECEIVE_BOOT_COMPLETED` | 收到设备重启等系统广播后，尝试重新安排已启用的本地提醒 | 属于系统广播相关声明，不是读取通讯录的运行时授权，也不表示任意后台联网；仍受政策确认、启用状态及系统条件限制 |

当前源码 Manifest 仅声明这三项权限，未新增 `INTERNET`、相机、位置或宽泛存储权限。导出和恢复使用系统文件选择器访问本人选定的文档位置。本轮未构建最终 APK，不能以源码 Manifest 替代最终合并清单核对。

## 信息处理事实

| 信息或行为 | 本机用途及范围 | 向渠道填写时需保留的边界 |
| --- | --- | --- |
| 联系人姓名、选填手机号、关系、备注 | 保存到本机账本，用于关联礼金、查询和统计 | 这是个人信息的本机处理；不能因“没有开发者服务器上传”就把所有问题一律填“否” |
| 礼金金额、日期、方向、事由、备注 | 本机记录、搜索、日历、统计 | 不描述为资金转账、支付或金融账户服务 |
| 通讯录预览数据 | 授权后在内存中读取、预览及匹配，确认后保存所选姓名、号码 | 预览遮罩不代表应用未读取完整号码；导入并非只读取用户尚未选择前的少量条目 |
| 独立提醒标题、日期、重复及启停状态 | 本机设置与系统通知调度 | 系统通知会处理显示内容，用户应避免在标题中填写不宜公开的信息 |
| 主题、语言、提醒设置、引导及隐私确认版本 | 本机记住选择与告知状态 | 不构成在线用户账号；不宣称不存在任何本地设置处理 |
| CSV、Excel、普通备份 | 写入本人通过系统选择的保存位置 | 文件未加密，持有人可能读取。导出记录不能用于礼账恢复 |
| 密码加密备份 | 使用本人当次提供的密码加密/解密，当前实现采用 PBKDF2-HMAC-SHA256 和 AES-256-GCM | 应用不保存备份密码，开发者不能找回密码或代为解密；不夸大为数据库全部加密或保证可恢复 |
| 本地恢复 | 替换联系人及礼金记录 | 非合并、无应用内撤销；不包含独立提醒、提醒设置、主题、语言等偏好 |
| 第三方文档提供方 | 用户可在系统选择器中主动选用云盘或同步目录 | 提供方可能按自己的规则上传/同步文件，不等于礼账提供云同步，也不能宣称文件绝不离开设备 |
| 系统浏览器访问公开链接 | 用户主动打开官网法律页面或工信部查询 | 外部网页有其访问处理范围；官网访问另见已批准网站说明，不能将 App 的本机处理概括到所有外部服务 |
| 联系开发者邮箱 | 本人主动发来的邮件会由运营者及双方邮件服务商处理 | 按已批准政策说明；勿要求用户发送完整账本、真实联系人、备份或密码 |

本机数据库没有礼账另设的独立密码加密。卸载或清除数据可能移除本机账本，不会一并删除此前导出到其他位置的文件。当前没有在线账户、远程账号恢复、云端账本或自动云同步。

本次查看的直接声明及相关源码未见账号登录、广告、行为分析、自动崩溃上传或网络识别 SDK 的接入。该事实不等于对全部传递依赖、最终包或操作系统信息处理作安全认证。
