# 商店材料的功能事实与源码依据

依据提交：`c3bbd5c7a8623ef491913245e3b8dd733365d177`。本轮只做源码静态审阅，没有运行产品测试；下列对应关系不能作为实机验收结论。

| 商店材料中的事实 | 现有源码依据 | 说明边界 |
| --- | --- | --- |
| 收礼、送礼、联系人、日期、事由及备注 | `app/src/main/java/com/yangsong/lizhang/domain/model/GiftRecord.kt`、`Contact.kt`、`ui/screen/` 中对应页面 | 不扩展为在线账本或资金交易 |
| 日历、搜索和统计 | `ui/screen/LedgerBrowseScreens.kt` 中 CalendarScreen、`SearchScreen.kt`、`StatisticsScreen.kt` 及对应 ViewModel | 静态存在功能入口，不声称已完成功能或性能验收 |
| 主动导入手机联系人 | `ui/screen/ContactImportScreen.kt`、`ui/viewmodel/ContactImportViewModel.kt`、`data/contact/DeviceContactDataSource.kt`、`domain/contact/ContactImportRules.kt` | 授权后读取带电话号码的条目用于预览，仅确认选中项后保存；不修改系统通讯录 |
| 本地独立日期提醒 | `domain/reminder/IndependentReminder.kt` 中 IndependentReminderPlanner、`ui/screen/LedgerBrowseScreens.kt`、`data/reminder/AndroidReminderRepository.kt` | 提醒单独创建；不声称录入礼金会自动建立提醒，也不保证精确送达 |
| 重启后恢复提醒调度 | Manifest 和 `ReminderRescheduleReceiver`、`ReminderCoordinator` | 重新安排已启用提醒，受政策确认、启用状态、权限与系统条件影响 |
| CSV、Excel 导出 | `domain/export/GiftRecordCsvFormatter.kt`、`GiftRecordXlsxFormatter.kt`、`ui/viewmodel/SettingsViewModel.kt` | 导出用于查看和整理，不提供 CSV/Excel 回导恢复 |
| 普通及密码加密备份 | `data/repository/RoomBackupRepository.kt`、`domain/backup/BackupArchiveCodec.kt`、`BackupEncryptionCodec.kt` | 普通备份未加密；密码备份需原密码，没有找回或开发者解密渠道 |
| 备份范围 | `BackupArchive` 仅持有 contacts、giftRecords 及版本/时间元数据 | 不包含独立提醒、提醒设置、主题、语言、引导进度、演示练习数据 |
| 覆盖式恢复 | `RoomBackupRepository.restoreBackup` 的数据库事务先清空礼金和联系人，再写入备份 | 不是合并，没有应用内撤销入口；不把格式校验解释为必定恢复 |
| 只访问本人选择的文件位置 | `ui/screen/SettingsScreen.kt` 使用 CreateDocument、OpenDocument | 提供方可能是第三方云盘，不能声称导出的文件永远只留本机 |
| 本机优先、无需账号、无内置业务上传 | Manifest、运行时依赖声明、现有法律正文、`domain/legal/LegalDocument.kt` | 基础库不等于在线采集；未解析最终 APK，商店问卷仍由本人按定义审定 |
| 图标沿用既有品牌资源 | `drawable-nodpi/launcher_cat.png`、`drawable/ic_launcher_foreground.xml`、`mipmap-anydpi-v26/ic_launcher.xml`、`values/launcher_colors.xml` | 只导出派生方形素材，不修改 Android 图标资源，不模拟真实页面截图 |

表中除第一行完整目录外，简称均相对于 `app/src/main/java/com/yangsong/lizhang/`。公开说明同时参考既有 `app/src/main/assets/legal/help.md` 和 `privacy.md`，未改动其已批准正文。
