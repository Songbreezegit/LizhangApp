## 最终实现

### 深浅色开关

记录 Switch 中心的窗口坐标，按 content 根位置转换为捕获/覆盖层共用坐标。点击开关、整行和无障碍切换均复用中心。使用 PixelCopy 捕获一次旧窗口，提交目标主题，实时页面始终不透明。新主题实际窗口绘制结束后启动揭示，Canvas 在旧画面上裁掉向外扩张的圆。

半径为中心到四角最大距离向上取整，再加 2px；420ms，FastOutSlowInEasing，双向均展开新主题，无缩放、平移、回弹或额外特效。2026-10-04 根据“切换太快”的反馈将时长由 360ms 增加至 420ms，约增加 17%；主题弹窗 240ms 和语言交接 140ms 保持原样。底部导航与页面共享同一原生覆盖层。开关提供即时目标反馈，圆从其中心开始揭示。系统栏图标在有效主题变化时单独更新，不把系统栏当作 Compose 快照。

### 主题选择弹窗

点击选项立即预览，点击完成关闭；不捕获画面，不叠加圆形过渡。页面与 Dialog 继承同一 240ms 颜色进度。Material 全部色槽、渐变、普通玻璃/毛玻璃透明度与边框连续插值，移除 luminance 阈值分支。文字交叉期间使用短暂轮廓阴影帮助辨认，端点排版与配色恢复原样。Dialog 尺寸、位置与透明度不动画，独立窗口 dim 不随进度变化。

有效深浅色相同的偏好变更只更新选中态，不启动整页动效。SYSTEM 模式下开关按实际主题显示，并切换为实际外观的相反手动模式。

### 语言

继续使用 AppCompatDelegate.setApplicationLocales。选中反馈实际绘制后关闭 Dialog；关闭语言 Dialog 的系统窗口动画，确认独立窗口真正分离后再捕获主页面，避免 dismiss 已启动但窗口仍在退出的残影。请求编号、目标语言与一次内存画面由 Activity 作用域 ViewModel 衔接重建。新 Activity 在首次绘制前安装旧画面；只允许目标语言的新 Activity 消费交接，避免全局 locales 提前更新使旧 Activity 抢先开始动画。

Activity 接收 locale/layoutDirection 配置后主动调用一次 recreate，仍实际重建，但保留旧窗口的最后已绘制画面，避免系统配置重启期间先清空合成窗口。新 Activity 重新绑定视图树所有者（包括返回键调度器），移除旧 ComposeView 并安装新内容。API 33 及以上通过 LocaleManager.systemLocales 判断系统语言，避免进程 Resources 混入应用语言。

导航由原 Navigation 保存机制恢复；导航条目必须达到 RESUMED。设置列表记录首项和偏移，等待真实视口及 Insets 恢复后还原，避免新 ComposeView 临时零 Insets 夹断偏移。此恢复也适用于关闭动画、不分配 Bitmap 的路径。目标配置、导航、列表和窗口实际绘制均确认后，以 140ms 淡去旧覆盖画面；实时新页面 alpha 始终为 1。API 29 以上硬件窗口等待帧提交回调，低版本在 onDraw 返回后确认 Canvas 绘制结束。140ms 不包含重建耗时，不通过固定等待帧数估计就绪。完全相同有效 locale 列表只提交偏好并立即更新语言选中态，不捕获或等待一次不会发生的重建。同选项不提交，重建不重复调用语言设置。

### 中断与内存

只保留一棵实时 LiZhangNavGraph。Bitmap 不进入 Bundle、rememberSaveable 或 SavedStateHandle，不落盘或写日志。8MiB 预算，超过预算按比例降采样；捕获失败/分配失败直接应用设置。请求只保留最新意图，未完成捕获串行处理，避免并存多个原尺寸画面。

捕获 600ms 超时，圆形覆盖 1500ms 超时，语言衔接 4000ms 超时。失败、中断、离开设置、后台和尺寸改变时撤除覆盖层并释放引用；语言仅在配置重建期间保留尚未消费的覆盖。动画比例为 0 时不分配快照或等待动效，直接应用设置。

## 独立提醒与空状态

按本轮补充需求，提醒与“记一笔”解绑。用户主动新增未来日期，默认一次，可选每年重复，支持编辑、停用、删除；今天及过去日期不能新建，错过时刻不补发。升级取消旧礼金推导闹钟，不迁移历史礼金为提醒。空状态移除第二只猫，保留顶部原插画、设置卡、紧凑空状态和新增入口。四语言同步，提醒存在本机私有偏好且不包含在礼金备份中。详情见 [独立提醒设计](提醒功能设计.md)。

Room 表、数据库版本 2、迁移、礼金备份格式 3 与礼金业务不变。
