## 本次核对的重点

- 主及合并 Release Manifest 未声明 INTERNET；有通讯录读取、通知和启动完成广播权限，合并清单另有 AndroidX 的应用自身签名级动态广播权限。
- 通讯录授权后读取导入候选，确认后仅保存选中姓名及规范化完整号码；不写系统通讯录。
- 当前为用户独立创建的提醒，不从礼金自动生成；提醒使用非精确系统调度。
- 普通备份为带校验的专用二进制文件，不等于加密；密码备份使用 PBKDF2 与 AES-256-GCM。
- 备份只包括联系人和礼金；不包括独立提醒或应用设置。恢复覆盖两张业务表，不合并账本。
- CSV／Excel 为未加密导出，不能作为礼账恢复文件。CSV 对公式前缀未作中和，列为上架前待评估项。

完整事实、准确源码路径与行号见 [应用行为审查](../website/docs/应用行为审查.md) 和 [备份提醒审查](../website/docs/备份提醒审查.md)。这些是源码证据，不代表法律、商店或真机验收完成。
