# 导航栏点击动效

- 保持原有布局、配色、图标和导航目的地。
- 按下时图标区域在 90 毫秒内缩小至 92%，松开或取消时在 180 毫秒内恢复。
- 选中颜色在 180 毫秒内过渡，胶囊底色在 200 毫秒内渐显或渐隐。
- 不使用额外波纹，避免出现导航栏外溢或文字下方矩形闪烁。
- 点击立即交给导航处理，不等待动画结束；当前项重复点击不触发导航。
- 选中状态由实际路由驱动，快速切换会从当前动画位置继续过渡。
- 保留 Tab 选择语义和完整点击区域，动画遵循 Compose 系统时长缩放。

验收关注：连续切换、按下后滑出取消、返回键选中态、系统关闭动画及深色模式。设备视觉验收需单独执行。
