## 渲染实现

使用稳定版 **dev.chrisbanes.haze:haze:1.6.4**，不升级 Compose BOM 2025.06.01、AGP 或 Kotlin。参考该版本的 [官方源码](https://github.com/chrisbanes/haze/tree/1.6.4/haze/src) 实现；已在项目当前依赖下编译通过。

FrostedGlass.kt 统一提供 frostedGlassFrame(hazeState, shape)。先采样页面图层，仅在浮层轮廓内绘制高斯模糊，再加轻 tint 和细边框，最后绘制清晰前景。不使用 Modifier.blur() 模糊浮层本身或整页输出。

| 参数 | 值 |
|---|---|
| BlurRadius | 20dp |
| 浅色 tint | surface × 0.18 |
| 深色 tint | surface × 0.32 |
| 边框 | onSurface × 0.12，1dp |
| 导航 / 保存栏圆角 | 30dp |
| FAB / 菜单圆角 | 20dp，沿用 ControlRadius |
| 外围阴影 | 6dp，沿用仅在轮廓外绘制的阴影 |
| 背景输入采样 | HazeInputScale.Fixed(0.3334)，前景不降采样 |
| 噪声 | 0 |
| 回退 tint | 与对应主题的正常 tint 一致 |

backgroundColor 是位于采样内容下方的底色，避免原始清晰背景从模糊图层的透明像素漏出；不是额外覆盖在采样内容上方的白色 Surface。三分之一分辨率采样使用 Haze 1.6.4 内标记 ExperimentalHazeApi 的配置项，仅局部 OptIn；依赖本身仍为稳定版本。

### 四个接入点

- LiZhangNavGraph 根部创建 HazeState，NavHost 为 source，BottomNavBar 为 effect。保留选中胶囊、按压缩放、选中动画和路由行为。
- AddGiftContent 自持页面 HazeState，AppScaffold 为 source，GiftSaveBar 为 effect。保持 Box Overlay、76dp 高、左右 16dp、navigationBarsPadding/IME 避让、loading、防重复保存、450ms 返回计时。
- ContactsContent 的 AppScaffold 为局部 source，scrim 和 GlassActionMenu 都在 source 外。菜单遮罩不参与 FAB 与菜单的采样。
- GlassFab 改用 56dp Box + clickable；展开项改用 Row + clickable，最小高度 48dp。全部使用同一 frame。保留橘色加号、45° 旋转、展开顺序、外部点击、返回键与管理模式行为。

普通卡片、输入框、弹窗、快捷入口和首页图标按钮未加入 Haze。原有普通 glassFrame 与新的 frostedGlassFrame 语义分开；非本轮目标的反馈提示条和年份菜单继续沿用原样式。

首页两个按钮放入独立 Row，Arrangement.spacedBy(10.dp)；按钮最小 48dp、图标 28dp 和标题的 weight(1f) 保持不变。设备测试覆盖 360dp、1.0/1.5 字号及浅深主题，验证按钮边界间距与点击尺寸。

## 旧系统与预览

API 26–30 由 Haze 1.6.4 自动禁用 blur，采用明确的低透明度 fallbackTint，保留轮廓、阴影和可点击内容。API 31+ 使用 RenderEffect 背景模糊。

Android Studio/Layoutlib 截图环境不能正确渲染该 GPU 效果，因此 LocalInspectionMode 下显式禁用 blur，预览基线验证布局和回退样式。不能把这些基线视为实际 GPU 模糊证据。真实模糊由 API 36 模拟器像素测试及设备截图单独验证。

## 十秒滚动与性能限制

最初同时运行两台模拟器、在 Compose 同步手势中插入截图，帧统计被明显干扰。最终关闭 API 26 模拟器，计时段改用 UiDevice 的真实墙钟触摸，不在段内截图或等待 Compose 空闲，并将背景采样从 0.5 降为 **0.3334**。高斯半径仍为 20dp。

| 最终 API 36 结果 | 浅色 | 深色 |
|---|---:|---:|
| 持续往返手势 | 31 次 | 34 次 |
| 渲染帧数 | 461 | 485 |
| Janky frames | 105（22.78%） | 95（19.59%） |
| 帧耗时中位数 | 23ms | 24ms |
| P95 | 34ms | 34ms |

连续触摸计时至少 10 秒；FAB 与导航滚动前后 bounds 完全一致。背景刷新与保存反馈测试通过，截图样本未见黑块、错位或残影。

**性能验收保留项：模拟器仍有慢帧，不能宣称“完全不掉帧”。** 当前结果包含模拟器/测试宿主开销，不能直接代表荣耀 100 Pro，也未做同环境无 blur 的严格 A/B。需在荣耀 100 Pro 上按首页、联系人、记一笔浅深主题重复验收流畅度；本次交付不将此项标为通过。
