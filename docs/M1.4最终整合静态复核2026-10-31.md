## Popup 定位与测试修订

生产环境仍使用独立、不可聚焦的 `Popup`。年份窗口沿用入口下方 8dp 的锚点；联系人窗口沿用 56dp 按钮的右下锚点。弹窗前景与背景分属窗口，不能直接比较各自的 `boundsInRoot`，也不能仅把它机械替换为各窗口的 `boundsInWindow`。

新增测试辅助函数，将节点经过裁剪的根坐标边界按 `positionOnScreen - positionInRoot` 平移到屏幕坐标，保留裁剪与实际显示尺寸。已根据项目缓存的 Compose UI 1.8.3 源码核对上述 API；公开说明见 [SemanticsNode](https://developer.android.com/reference/kotlin/androidx/compose/ui/semantics/SemanticsNode)。

- 年份测试继续验证选中状态、选择回调、入口再次点击、外部点击、返回优先、页面滚动关闭、菜单内部滚动、8dp 间距、左对齐、168dp 宽度、240dp 限高及至少 48dp 触控高度。几何比较改用屏幕坐标，并增加独立 Popup 祖先断言；外部点击明确定位包含首页列表的页面根，避免多根匹配歧义。
- 联系人测试保留原有展开/收起、外部点击、两个独立回调、管理模式隐藏、千条联系人与提醒等全部断言；增加收起/展开按钮屏幕锚点比较、真实触摸只触发一次操作且不穿透背景联系人、返回先关闭菜单再交给页面的回归代码。
- 生产逻辑静态核对：Popup 不抢焦点，返回仍交给页面 `BackHandler`；外部事件仍由页面处理。年份菜单内部滚动留在菜单窗口，页面滚动关闭菜单；联系人外部遮罩消费页面点击，菜单操作先关闭再回调。没有新增回调队列或改变导航流程。

上述为测试代码与设计核对，**全部待本人验证**，不是已经运行的回归结论。

## 毛玻璃窗口生命周期

`FrostedOverlayWindow` 的资源作用域覆盖当前管理器、视图、Dialog 窗口与 Popup 类型。离场时注销对应系统监听；视图仍连接时，将本窗口的模糊半径和 dim 置零并清除 Blur/Dim 标志。已移除的窗口由系统清理，不更新 Activity 窗口，也不清理其他浮层。

系统关闭模糊时清除当前窗口的 Blur 标志并沿用 24% dim 降级；恢复支持时按当前进度设置半径。Android 8–11 不调用 API 31 的模糊与监听接口，继续透明面板/缩放/遮罩显示。26px、42%、0.94→1 和 260ms 样式参数未改动。

嵌套日期窗口有独立属性与监听，关闭时只清理自身，下层提醒编辑窗不受影响。退出动画继续保持零，不恢复系统窗口退出动画；原有语言选择的选中帧确认、`doOnDetach` 后再请求页面捕获的交接不变。主题动画协调器、请求锁、颜色完成回调、语言切换源码及业务层均未修改。上述生命周期判断均为静态核对，待本人通过系统模糊切换、嵌套开关、主题和语言切换重新验收。
