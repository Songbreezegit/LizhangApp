# 礼账 App：Stitch 原型提示词

## 使用方法

先使用“全局提示词”生成一个完整方向，再分别使用页面提示词补齐页面。建议生成 3 个风格方向，只选择一个继续深化。选定方向后导入 Figma，整理为变量、组件和可点击流程；不要直接使用 Stitch 导出的 HTML/CSS 作为 Android 代码。

## 全局提示词

```text
设计一款中文 Android 原生应用“礼账”，用于记录家庭礼金和人情往来。首批验证用户是开发者父母，他们长期使用纸质礼簿；但产品面向所有有礼金记录需求的中文用户，不要把它设计成老年专用 App。

产品不是普通财务记账软件，而是现代家庭礼簿。核心目标是快、简单、可靠：新增一条记录不超过 3 步，联系人历史记录能快速查询，数据保存和导入过程必须让用户安心。

请使用 Material 3 的 Android 交互规范，设计 Pixel 9 尺寸的高保真中文界面。视觉采用“简约中国古代风”：把中国传统礼簿、书册和宋式审美中的秩序、留白、含蓄转译为现代移动界面，而不是制作仿古道具。

使用宣纸暖白作为背景、墨黑或黛色作为主要文字、克制的印章红作为品牌色和主要操作色，可少量使用低饱和青灰或茶褐。标题可以有现代宋体/衬线气质，正文和表单必须使用清晰的现代中文字体。使用细分隔线、书页式分区、小到中等圆角和现代线性图标，减少西式悬浮卡片堆叠。可以极轻地借鉴印章、书签、线装书或回纹边界，但不能影响可读性。

保持清晰字号和宽松点击区域，这是面向所有用户的普适易用性设计，不要出现“老年模式”标签或陈旧感。避免宫廷奢华、红金婚庆、武侠游戏、国潮海报、拟真卷轴、龙凤祥云、铜钱堆叠、毛笔正文、厚重纸张纹理、玻璃拟态、霓虹色和复杂渐变。

底部导航包含：首页、联系人、记一笔、我的。首页突出“记一笔”主操作，并提供收礼记录、送礼记录、日历和统计快捷入口。金额必须同时使用文字标签和颜色区分收到/送出。所有用户可见文字使用简体中文。

请保持统一的颜色、字体、间距和组件规则，并为页面补充空状态、加载状态和错误状态。需要设计：首页、新增礼金、联系人、联系人详情、搜索、统计和设置。
```

## 首页提示词

```text
为“礼账”设计首页。延续简约中国古代风和现代礼簿秩序感。顶部是礼账标题和明确的搜索入口；页面最重要的操作是醒目的印章红“新增礼金”按钮。提供“拍照导入”“联系人”“统计”三个中文快捷操作。本年摘要展示收到、送出、净往来，最近记录展示姓名、事件、日期、收到或送出标签、人民币金额。信息层级清楚、留白克制，适合广泛年龄用户，不要像专业财务仪表盘，也不要像仿古网页。同时生成首次使用的空状态版本。
```

## 新增礼金提示词

```text
为“礼账”设计新增礼金页面。字段依次为姓名、金额、日期、事件类型、收到/送出、备注。姓名可搜索已有联系人，也可以快速新建；金额使用适合数字键盘的大输入框；收到/送出使用文字清楚的分段选择；事件类型包含婚礼、满月、生日、乔迁、节日、白事、其他。底部固定主要按钮“保存记录”。请展示正常状态、字段错误状态和保存成功反馈，确保用户最多 3 步完成核心输入。
```

## 联系人与详情提示词

```text
为“礼账”设计联系人列表和联系人详情。联系人列表支持姓名或手机号搜索，每项展示姓名、累计收到、累计送出、净往来，优先突出姓名和最近往来。联系人详情顶部展示联系人信息和三项金额汇总，下方历史记录按年份分组，单条记录包含事件、日期、方向、金额和备注摘要。提供“新增往来”和“编辑联系人”文字操作。生成空记录和无搜索结果状态。
```

## 搜索与统计提示词

```text
为“礼账”设计搜索和统计页面。搜索支持姓名、手机号、备注，结果按联系人归组并突出匹配文字。统计支持本年、上一年和自定义年份，展示收到、送出、净往来，并按事件类型和联系人统计。图表旁必须显示清晰的中文标签与精确金额，不能只依赖颜色。整体保持易读，不做专业财务软件式复杂图表。
```

## 设置提示词

```text
为“礼账”设计设置页面。分组包含数据备份与恢复、Excel/CSV 导出、主题、字体说明、关于与隐私。备份、恢复等高风险操作使用清楚的解释文字；恢复数据前必须二次确认。页面简洁，使用标准 Android 设置列表，不添加账号、云同步、会员或社区入口。
```

## 反向约束

如果生成结果出现以下问题，继续要求 Stitch 修正：

- 删除英文、繁体字和无意义占位文字。
- 减少底部导航数量，不超过 4 项。
- 保持正文清晰、点击区域充足，但不要使用“老年版 App”的视觉语言。
- 减少装饰性卡片和渐变，突出新增、搜索和联系人三个核心任务。
- 删除宫廷红金、龙凤祥云、铜钱、卷轴、武侠游戏和国潮海报式装饰，恢复简约书册与宋式留白方向。
- 不要加入登录、会员、云同步、预算、社区或聊天功能。
