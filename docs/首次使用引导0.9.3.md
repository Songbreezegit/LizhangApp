# 首次使用引导 0.9.3

版本为 `versionName = 0.9.3`、`versionCode = 13`。基线为 `origin/main` 的 `6df41375e89aaae4b0c0f926f69cea91ed9d93e5`，开发分支为 `feat/v0.9.3-onboarding`，不自动合并 main。

## 体验与范围

- 新增三页首次启动引导：人情记录、三个核心功能、数据与权限说明。前两页支持跳过，最后一页“开始使用”。使用官方 HorizontalPager 默认翻页，不增加依赖或复杂动画。
- Page 2、Page 3 的系统返回键先回上一页；首次 Page 1 沿用 Activity 返回，不标记完成。
- “我的 → 使用引导”使用独立的手动查看模式，最后按钮为“完成”，返回原设置页。完成、跳过或返回都不改变首次完成状态。
- 首页无任何礼账记录、联系人页无联系人且未搜索时，各展示一次轻量提示。展示即保存已看状态，触摸不消费原事件，点击空白、关闭或操作入口都可关闭。已有内容、加载中或错误状态不展示。
- 复用现有猫咪 PNG、AppGradientBackground、GlassCard、GlassButton 和颜色体系；四语言资源覆盖全部新增文案。小屏与大字体可纵向滚动，主要按钮保持可见。

本轮不修改礼金、联系人和提醒业务规则，不新增网络、统计 SDK、登录、OCR 或上传功能。

## 存储与升级兼容

`SharedPreferencesOnboardingRepository` 实现领域 `OnboardingRepository`；界面通过 `OnboardingViewModel` 读写，沿用现有小型偏好存储方式。私有文件为 `onboarding_preferences`，使用 SharedPreferences `apply` 保存，并通过 StateFlow 同步内存状态。

| 字段 | 初始值 | 消费时机 |
| --- | --- | --- |
| `onboarding_completed` | 全新安装为 false | 首次模式点击跳过或开始使用 |
| `home_record_hint_seen` | false | 空首页首次展示提示，或点击记一笔 |
| `contacts_hint_seen` | false | 空联系人页首次展示提示 |
| `contact_permission_explanation_seen` | false | 展示通讯录权限用途说明 |
| `notification_permission_explanation_seen` | false | 展示通知权限用途说明 |
| `contact_permission_requested` | false，兼容旧 `contact_permission/requested` | 明确继续并调用系统申请 |
| `notification_permission_requested` | false | 明确继续并调用系统申请 |

首次缺少 `onboarding_completed` 时集中捕获以下旧安装证据，任意一项成立即保存 true：

1. PackageInfo 的 `lastUpdateTime > firstInstallTime`，包括旧版安装后从未启动的覆盖升级。
2. 既有 `lizhang.db` 文件，包含空数据库，无需读取联系人或礼金内容。
3. 私有 `shared_prefs` 下已存在旧偏好 XML 文件。
4. AppCompat 已保存应用语言的私有文件。

检测在 AppContainer 最前面进行，早于 Room 或提醒仓库可能写入的文件。已经保存的 false 不会被后续默认文件、Activity 重建或更新覆盖成 true，未完成的新用户仍可继续引导。已完成的 true 同样直接复用。安装时间只用于应用自身升级判断，不读设备联系人或备份内容。

## 应用入口与恢复

MainActivity 保留原 AppearanceTransition 宿主与语言重建逻辑，根据完成状态展示 OnboardingScreen 或唯一的 LiZhangNavGraph。手动查看只是现有导航中的 `onboarding_review` 页面。Pager 使用官方保存状态，支持旋转和语言重建恢复；业务导航保存与恢复策略不变。

首次模式没有业务导航条目，由当前 Activity 的生命周期回调同步引导就绪状态；语言重建后等待新 Activity 的资源、恢复状态和窗口焦点，再核对页码。手动查看继续使用原业务导航的就绪判断。

新安装未完成引导时不初始化提醒仓库或启动提醒协调；完成后启动既有协调器。老用户仍在 Application 启动时恢复提醒，协调器原有幂等逻辑不变。

## 权限按需说明

通讯录：用户主动选择通讯录导入，已有权限则沿用导入流程；首次无权限先展示用途说明，点击“继续”才调用 `READ_CONTACTS`。取消后仍可返回或手动添加。系统拒绝后只在下一次主动操作时处理，永久拒绝提供系统设置入口。从设置恢复授权时沿用原生命周期权限复查。

通知：用户主动开启提醒总开关后，Android 13 及以上检查 `POST_NOTIFICATIONS`，先说明、后申请；暂不或拒绝保持关闭。永久拒绝改为前往系统通知设置，返回且授权成功后启用提醒。Android 12 及以下直接使用原启用逻辑。每个独立提醒的编辑、调度和持久化保持原样。

首次引导不申请任何权限、不读取通讯录、不访问用户备份、不联网。`android:allowBackup="false"` 与数据提取配置不变。数据库版本仍为 2，MIGRATION_1_2 不变；礼金备份格式仍为 3。
