# v0.9.5 导航栏动效

2026-10-07，版本 `0.9.5 / 15`，分支 `codex/v0.9.5-navigation-effects`。

## 参考与效果

参考用户指定的 [猫sir：底部导航菜单切换效果 3](https://www.xiaohongshu.com/explore/6a4a9acf000000002100915c)。实际查看开头效果演示及曲线制作部分，采用选中图标上浮为圆形按钮、圆弧凹槽与按钮同步移动、原图标落回的交互。保留礼账现有玻璃配色、四个图标和本地化标签。

## 实现边界

底栏沿用四个等宽入口和完整 Tab 选择语义，点击立即触发现有导航，选中项由实际目的地驱动，当前页重复点击不重复导航。凹槽使用真实路径裁剪，玻璃模糊、边框和阴影共用同一轮廓；上浮圆钮与主体分开采样背景。

位置与图标升降使用 380ms 缓动。快速切换从当前动画位置继续；初次显示直接位于当前项；系统动画缩放为零时直接到达目标。保留底部安全区、功能引导真实目标锚点与多语言标签，标签允许自然换行。联系人悬浮按钮额外计入系统导航安全区，避免窄屏大字体时与底栏相交。

本版本同时纳入 [多语言扩展与联系人页调整](多语言扩展与联系人页调整.md) 和用户追加授权的 [视觉层级调整](视觉层级0.9.5.md)。未修改 Room、备份格式或页面业务导航。
