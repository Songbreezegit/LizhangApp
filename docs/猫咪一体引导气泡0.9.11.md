# 猫咪云朵一体引导气泡（0.9.11）

日期：2026-10-09。版本：`0.9.11 / 21`。分支：`codex/figma-guide-nav-startup`。

用户真机截图指出：单独的矩形与三角拼接造成割裂；随后指定不规则云朵、上沿慵懒趴猫、删除可见进度，并强调主体以白色调为主。本轮重新生成适合礼账的可爱气泡参考，再以 Figma 更新所有引导气泡，仅调整气泡样式。

## 样式

云朵主体与曲线尾巴作为一个闭合路径，统一填色和外轮廓描边；尾根不再存在横向边框。四边以宽缓的不规则弧线形成云朵，尾根与圆润尖端采用曲线过渡，尖端继续指向真实目标。上沿留出慵懒趴猫的独立装饰空间，保留礼账蓝眼白猫和心形红包身份，避免遮挡文字、按钮和真实控件。

云朵在浅色和深色页面均以柔和白色 `#FFFCF7` 为主体，搭配深色文字、浅暖灰轮廓和橘色动作按钮；该局部配色不改变页面全局主题。趴猫默认占用 128 × 64dp，顶部装饰空间参与整体测量；空间紧张时优先缩小装饰，并避开上沿尾巴。

原有十一种说明、跳过／下一步／开始记账／知道了文案、页面首次触发、联系人回填、用户操作及已读状态均不改变。按用户要求删除可见进度条和“1/5”，内部步骤与无障碍语义进度仍保留。气泡内容仍保留长文字滚动、大字体按钮换行、RTL 和无障碍语义；继续采用原 240ms 线性入场与 8dp 位移，系统关闭动画时显示终态。

## 设计来源

本轮使用内置 imagegen，以已有 `launcher_cat.png` 为品牌身份参考，先生成透明慵懒趴猫，再生成不规则白色云朵完整气泡视觉稿。猫咪生产资源保存为 `app/src/main/res/drawable-nodpi/guide_lounging_cat.png`；最终参考图保存为 `build/deliveries/2026-10-09-unified-cat-guide/imagegen/cloud-guide-bubble-reference.png`，两份完整提示保存为同目录 `cloud-mascot-prompt.txt` 与 `cloud-bubble-prompt.txt`。初始圆角矩形参考保留作历史，未用于最终设计。整张生图仅作为参考，App 继续使用原生文字与按钮，Figma 气泡保留可编辑的轮廓、文字和控件。

Figma 最新设计与节点证据见 [猫咪气泡 Figma 交接](猫咪一体引导气泡Figma0.9.11.md)。
