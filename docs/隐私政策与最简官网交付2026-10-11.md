## 用户文案与实际源码核对

| 文案事项 | 当前实现与依据 |
| --- | --- |
| 无账号、广告、云同步与业务数据上传 | Manifest 无 INTERNET；app/build.gradle.kts 显式依赖为本地界面、Room、协程及 Haze，无账号或统计上传 SDK |
| 联系人和礼金保存在本机 | data/local/entity/ContactEntity.kt、GiftRecordEntity.kt；RoomContactRepository、RoomGiftRecordRepository |
| 主动导入才请求通讯录权限 | ui/screen/ContactImportScreen.kt 的用途说明与 RequestPermission；DeviceContactDataSource 只查询 Phone.CONTACT_ID、DISPLAY_NAME、NUMBER |
| 读取范围与预览 | 导入先读有号码的候选集合，内存预览；ContactImportRules 过滤无效信息、规范化并按号码去重和遮罩展示 |
| 默认选择与保存规则 | ContactImportViewModel 默认选择 NEW、同名不同号需核对，搜索保留选择；ContactDao.importDeviceContacts 在事务内再次去重，仅保存选中姓名和完整号码 |
| 通知仅在主动开启时申请 | ui/screen/LedgerBrowseScreens.kt 的提醒系统通知入口及 POST_NOTIFICATIONS 申请；拒绝不影响记账 |
| 独立提醒标题及日期可能展示 | AndroidReminderRepository 的 NotificationCompat.setContentTitle/setContentText；私有设置保存提醒，不读取礼金表 |
| 普通备份、CSV、Excel 未加密 | RoomBackupRepository、GiftRecordCsvFormatter、GiftRecordXlsxFormatter；密码备份才调用 BackupEncryptionCodec |
| 密码备份的保护与限制 | PBKDF2-HMAC-SHA256、AES-256-GCM，最少 8 字符；密码不保存，无找回渠道，不使数据库或导出文件同时加密 |
| 恢复整体替换、不是合并 | RoomBackupRepository.restoreBackup 事务内先清空礼金与联系人，再插入备份数据 |
| 备份不包含提醒和设置 | BackupArchive 仅有联系人及礼金；独立提醒、主题、语言、引导偏好另行保存 |
| 删除联系人连带礼金、不动系统通讯录 | GiftRecordEntity 外键 CASCADE；系统通讯录数据源没有写入或删除操作 |
| 文件服务由用户选择、其自身可能同步 | SettingsScreen 的 CreateDocument/OpenDocument 与 contentResolver，只访问所选文件；未扫描整个存储或直接联网上传 |
| 查看、更正、删除及撤回权限 | 保留联系人、礼金、提醒的现有编辑删除入口；系统权限可撤回；无账号注销或远程删除功能 |
| 第三方本地资源 | AndroidX/Compose、Room、协程、Haze；Lucide 为本地 ImageVector，许可随包保存 |
| 临时画面与 Debug 诊断 | AppearanceTransition 使用内存窗口画面；AppearanceTransitionViewModel 清理引用；ThemeOperationDiagnostics 仅 Debug 界面状态，不记录业务隐私或上传 |
| Android 系统自动备份 | allowBackup=false、fullBackupContent=false，data_extraction_rules 排除系统云备份与设备迁移的数据范围 |

源码路径以 `app/src/main/java/com/yangsong/lizhang/` 为前缀；Manifest 为 `app/src/main/AndroidManifest.xml`。上述为源码核对，不表示物理设备、商店或法律验收。

仅使用静态 HTML、CSS 和既有小猫品牌图片。没有运行时 JavaScript、后端、数据库、账号、广告、统计、Cookie、用户追踪或第三方字体 CDN。Markdown 文本及原始 HTML 全部转义，链接限制为已知站内页面或 HTTPS；不执行嵌入内容。
