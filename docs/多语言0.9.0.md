# 礼账 v0.9.0 多语言

## 功能与边界

- 版本为 `0.9.0`（`versionCode = 10`）。「我的」原有外观分组新增「语言」入口，右侧显示当前选择。
- 复用玻璃弹窗，提供跟随系统、简体中文、English、日本語、한국어；四种语言名称始终使用自称。
- 中文品牌为「礼账」，其他三种语言统一为「Lizhang」。文档和开发注释继续使用中文。
- 不修改 Room 版本、表结构、迁移、联系人去重、统计、提醒调度规则或备份协议。不新增联网权限、账户、云同步、OCR 或多币种。

## 官方语言机制

`MainActivity` 使用 `AppCompatActivity`，通过 `AppCompatDelegate.setApplicationLocales` 切换，交由官方机制重建页面。空 LocaleList 表示跟随系统，其他映射为 `zh-CN`、`en`、`ja`、`ko`。

Android 13 及以上由系统保存应用语言，并通过 `locales_config.xml` 声明支持列表；Android 12 及以下启用 AppCompat 的 `autoStoreLocales`。不额外在 SharedPreferences 或 Room 保存语言。`AppLanguage` 只描述展示选择，不参与业务判断。

通知通过 `ContextCompat.getContextForLanguage` 读取应用语言，避免旧 Android 的后台 Context 使用系统语言。系统自动备份仍然禁用。

参考：[Android 应用语言官方说明](https://developer.android.com/guide/topics/resources/app-languages)、[AppCompatDelegate](https://developer.android.com/reference/androidx/appcompat/app/AppCompatDelegate)。

## 资源维护

手工维护四份资源，字符串和复数资源的名称、类型及参数保持一致：

| 目录 | 语言 |
| --- | --- |
| `values/strings.xml` | 默认简体中文 |
| `values-en/strings.xml` | 英文 |
| `values-ja/strings.xml` | 日文 |
| `values-ko/strings.xml` | 韩文 |

构建任务 `generateChineseResources` 从默认资源生成 `build/generated/chineseResources/values-zh/strings.xml`，使 `zh-CN,en-US` 等语言列表优先匹配中文，不会跳过无语言限定的默认资源而匹配英文。生成文件不提交，也不单独编辑。

资源打包限制在四种支持语言，避免依赖库的其他语言造成界面混用。单一不支持的系统语言自然回退为默认中文；多语言系统列表遵循 Android 原生匹配顺序。

记录数量、导入联系人数量、批量删除数量、删除确认和提前提醒使用 `plurals`，英文提供 `one/other`。多种数量同句出现时采用独立数量标签，避免错误拼接单复数。

新增语言时添加完整资源，再更新 `AppLanguage`、显示名称映射、选择器名称资源、`locales_config.xml`、资源打包语言列表与测试；不改业务层。

## 格式、字体与兼容

界面日期、月份、日历标题使用当前页面 Configuration 对应的 Locale。数量继续通过带位置参数的 Android 资源显示，金额格式按 Locale 展示但货币固定为 CNY，内部金额仍以分保存。格式器按语言缓存，语言切换不会复用旧语言格式。

CSV 和 Excel 的列名、工作表名、方向及预设事件使用资源翻译，点击导出时由界面层把文案快照传给 ViewModel 和纯 Kotlin 格式器，业务层不读取 Locale。导出数值和日期保留稳定格式；CSV、Excel 和备份的建议文件名统一为 `Lizhang_`、`Lizhang_backup_`、`Lizhang_encrypted_backup_` 前缀。自定义事件、姓名及用户备注原样保留，不自动翻译。

使用系统字体回退，不引入额外字体文件。语言选项和设置项允许换行；记录姓名限制合理行数，大字体下金额移至内容下方，避免与多语言方向标签争夺水平空间。导航和页面视觉体系保持原样。

## 验证

新增 `LocalizationResourcesTest` 检查四套资源键、资源类型、位置参数、英文复数、语言自称、日期格式缓存和人民币金额精度。

新增 `LocalizationInstrumentedTest` 检查四语言、未支持语言回退、显式中文优先匹配、语言弹窗切换、重建后的选择以及恢复跟随系统。`LocalePersistenceInstrumentedTest` 的两个方法需分别附带 `localePersistencePhase=setup/check` 运行，中间执行 `am force-stop`，验证冷启动持久化；普通全套运行时跳过这两个协议步骤，避免依赖测试顺序。

新增 `LocalizationScreenshotTest` 覆盖四语言设置页、英日韩窄屏大字体语言弹窗及深色模式，共 11 张。原有 90 个用例显式指定 `Preview.locale = "zh-rCN"`，避免国际化后预览器默认英文造成混合文案；相应更新资源语言标识、日期、版本和新增语言入口的基线，清理被替代的旧文件。已人工检查中文表单、深色首页、窄屏英文设置与日语/韩语弹窗。
