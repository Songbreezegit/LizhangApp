# 毛玻璃浮层统一

日期：2026-10-30。基线：`8d560528fc47f013d40fec1dbceffd98cb0a6ce2`，对应上一轮 `1.0.0 / 24` 测试包。独立分支：`feat/frosted-overlay-motion`，不合并 main 或 M1.4 分支。

## 样式与范围

根据本人提供的提醒时间、提醒日期、联系人菜单、备份操作和语言选择五张截图，统一应用自有弹窗、模态底部面板及展开菜单。

| 参数 | 实现 |
| --- | --- |
| 背景模糊 | 同一入场进度驱动原生窗口模糊半径 `0 → 26px`，按物理像素设置 |
| 面板底色 | 浅色模式白色、透明度 42%，对应 `rgba(255,255,255,0.42)`；深色沿用主题表面色，透明度同为 42% |
| 面板入场 | `0.94 → 1` 缩放并淡入，260ms，`FastOutSlowInEasing`；系统关闭动画时直接显示最终状态 |
| 背景明暗 | 支持模糊时轻遮罩 8%；不支持或系统关闭模糊时遮罩 24% |
| 形状与内容 | 延用既有圆角、字体、按钮、危险操作及确认/取消语义；不修改文案 |

`FrostedOverlay.kt` 集中管理参数、动画、窗口模糊、日期选择、底部面板与菜单窗口。共享 `GlassDialog` 覆盖语言、主题、备份、密码、恢复、提醒、权限说明、放弃编辑、删除及自定义事由等弹窗，避免逐页复制效果。

| 入口 | 接入点 |
| --- | --- |
| 提醒时间、提醒日期、提醒编辑等确认弹窗 | `GlassDialog`；时间选择器外层改为透明，表盘和选中颜色保留 |
| 提醒编辑中的日期选择 | `GlassDatePickerDialog`；日期选择器背景透明，日期限制不变 |
| 记账选择联系人、联系人详情筛选 | `GlassModalBottomSheet`，保留原有手势与回调 |
| 联系人展开菜单 | `GlassAnchoredPopup`，移除原背景色遮罩，保留页面外部点击、返回和管理模式关闭；菜单锚点保留 |
| 年份菜单 | `GlassAnchoredPopup`，保留年份来源、选中勾号、内部滚动、入口再次点击和页面滚动关闭 |

菜单移到独立窗口后，背景模糊不处理前景文字和按钮；年份菜单不再沿用旧的展开高度动画。普通内容卡片、行内帮助和功能引导气泡不作为独立弹窗处理。系统权限、文件选择器和系统设置由 Android 绘制，本轮不改变其界面。

## 兼容与生命周期

Android 12（API 31）以上使用 `WindowManager.LayoutParams` 的 `FLAG_BLUR_BEHIND` 与 `blurBehindRadius`。这与 CSS `backdrop-filter` 的用途对应，不在 Android 中引入 WebView 或 CSS。

原生跨窗口模糊受设备 GPU、系统设置及省电等状态影响。代码读取可用状态，并注册/注销系统状态监听；Android 8–11 或系统关闭模糊时，仅保留透明面板、缩放和轻遮罩，不能视为已经实现真实背景模糊。依据：[Android 窗口模糊说明](https://source.android.com/docs/core/display/window-blurs)、[窗口参数 API](https://developer.android.com/reference/android/view/WindowManager.LayoutParams#setBlurBehindRadius(int))。

每个浮层只调整自己的窗口属性，不修改 Activity 的窗口、主题锁或语言切换流程；组合离场会取消入场协程、注销模糊监听，窗口移除后由系统解除其背景模糊。语言选择仍沿用原有选中绘制确认、弹窗分离后再捕获页面的交接逻辑。嵌套日期选择关闭后，底下的提醒编辑窗仍保留自身浮层效果。
