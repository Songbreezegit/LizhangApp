# 按页首次引导 Figma 交接（0.9.8）

日期：2026-10-08。版本：`0.9.8 / 18`。

本轮根据用户提供的竞品参考，采用遮罩聚焦、短气泡和真实入口操作。首次进入先介绍最主要的记账功能，其余功能在用户第一次进入对应页面时单独介绍。沿用礼账现有配色、中文与页面结构，没有复制竞品角色或插画。

## 动效与外观参数

Figma MCP Starter 额度已用尽，用户恢复模型额度后重试仍返回 Figma MCP 配额限制。本轮实际编辑通过 Figma 浏览器编辑器完成，未取得 MCP `get_motion_context` 回读。最终稿参数依据编辑器 Motion 时间线与 Easing 面板核对。

| 轨道 | 节点 | 0ms | 240ms | 曲线 |
| --- | --- | --- | --- | --- |
| 气泡 Position | `48:1331 / 气泡动效_240ms_Linear` | X `868`，Y `1563.5` | X `868`，Y `1555.5` | Linear，`(0, 0, 1, 1)` |
| 气泡 Opacity | 同一节点 | `0%` | `100%` | Linear，`(0, 0, 1, 1)` |
| 遮罩 Opacity | `48:1297 / 遮罩动效_240ms_Linear` | 对象 `0%` | 对象 `100%` | Linear，`(0, 0, 1, 1)` |

Position 的浏览器读数采用图层中心坐标，两端差 `8px`，对应 App 中相对静态布局的 `+8dp → 0`。遮罩黑色填充自身透明度为 `46%`，乘以上述对象透明度，实际遮罩由 `0 → 0.46`。焦点框采用现有强调色，稿中线宽 `2px`。

气泡父组包含全部十一场景的独立气泡子组，遮罩父组包含全部十一场景的挖洞遮罩。总览统一播放同一段入场，时间线实际为 **3 条轨道、6 个关键帧、240ms**；没有计时串联页面或长流程自动演示。App 在对应页面独立触发同一参数。编辑器默认 Opacity 曲线曾为 `(.5, 0, .5, 1)`，已逐轨改成 Linear，并通过 Easing 面板确认。

建议映射：气泡距屏幕水平边缘 `16dp`，内部 `18dp`，圆角 `20dp`；与目标间隙至少 `12dp`；目标边框向外扩展 `6dp`，默认圆角 `16dp`。标题 `16sp`、正文 `14sp / 22sp`。气泡、按钮和底色复用 App 现有主题，适配深色、字体放大及系统栏；系统关闭动画时直接显示最终状态。遮罩外部不能妨碍用户正常退出，焦点内真实控件保持操作。
