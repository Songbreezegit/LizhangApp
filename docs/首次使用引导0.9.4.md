## 四步体验

原三页 Onboarding 保留视觉、Pager、四语言和权限说明。全新用户点击“开始使用”或“跳过”后进入首页，开始最多四步的功能引导：

| 步骤 | 实际目标 | 气泡说明 | 直接点击入口后的状态 |
| --- | --- | --- | --- |
| 1 / 4：记一笔 | 底部记一笔 | 从第一笔开始；从这里记录第一笔收礼或随礼。 | 正常打开 AddGift，保存 CONTACTS |
| 2 / 4：联系人 | 底部联系人 | 管理联系人；把常用联系人整理起来，之后记账会更方便。 | 正常打开 Contacts，保存 REMINDERS |
| 3 / 4：提醒 | 首页顶部通知按钮 | 别忘了重要日子；在这里设置提醒，重要日期可以提前知道。 | 正常打开 Notifications，保存 SETTINGS |
| 4 / 4：我的 | 底部我的 | 更多都在这里；主题、语言、备份和使用引导都可以在这里找到。 | 正常打开 Settings，保存 COMPLETED |

“下一步”只推进步骤，不执行导航，最后一项按钮为“完成”。每步都有“跳过引导”，立即永久结束整个流程，不提供另有含义的关闭 X。点击其他入口不会跳步骤。离开首页后气泡暂停，只有用户自己回到首页才显示当前步骤；不会自动把用户拉回首页。

## 状态机与持久化

`OnboardingState.featureGuideStep` 是唯一的功能引导状态，领域枚举为 `ADD_RECORD → CONTACTS → REMINDERS → SETTINGS → COMPLETED`。仍使用 `SharedPreferencesOnboardingRepository`、`OnboardingRepository` 和 `OnboardingViewModel`；同一私有文件 `onboarding_preferences` 增加稳定字符串 key `feature_guide_step`，对应 `add_record / contacts / reminders / settings / completed`。不增加第二个完成 boolean 或第二套偏好文件。

仓库集中初始化并保存迁移结果。界面只观察 StateFlow 和发送意图；推进检查当前步骤与事件携带的预期步骤一致，避免重复点击同一气泡越过下一步。首次三页完成标记只控制引导是否可以开始；可见性为三页已完成且步骤未完成，再由导航图限制为首页处于 RESUMED。不读取账本是否为空，删除所有礼账也不会重新触发。旋转、Activity 或 ViewModel 重建、语言切换及进程重启重新读取保存的步骤，控件坐标重新测量。

## 真实定位与点击

`LocalFeatureGuideTargetRegistry` 在现有 `LiZhangNavGraph` 提供共享轻量 registry。底栏三个现有入口和 HomeHeader 通知按钮使用 `Modifier.featureGuideTarget(...)`，通过 `onPlaced / onGloballyPositioned / boundsInRoot` 报告真实坐标。同窗目标先放置、气泡后放置，在首帧读取实际位置，截图预览也无需硬编码坐标；放置顺序采用官方 [onPlaced API](https://developer.android.com/reference/kotlin/androidx/compose/ui/layout/onPlaced.modifier)。组件只报告位置，不判断步骤；离场时按注册所有者清理，避免旧组件移除恢复后的新坐标。目标未布局、滚出列表或仅部分可见时暂停气泡并移除其语义节点，重新完整出现时恢复。

`FeatureGuideOverlay` 位于原 Box 中 NavHost、BottomNavBar、Snackbar 之后，是普通 Compose Layout 层。把目标根坐标转换为自身局部坐标，依实际目标上下空间决定气泡位置；底栏目标优先上方，顶部提醒优先下方。结合 `WindowInsets.safeDrawing`、实际底栏顶部、屏幕边缘间距限制可用区域，宽度不超过可用宽度 86% 并限制最大 360dp。窄屏和大字体时说明可滚动、操作可换行。复用 GlassCard、玻璃按钮及 MaterialTheme 色彩，目标仅绘制 2dp 品牌色圆角描边，无黑色蒙层或循环动画。

整屏 Layout 和高亮没有点击处理；只有气泡及其按钮消费自身触摸，真实入口和其他 UI 保持正常点击。现有 `go(AppDestination)` 把四种 Destination 映射为目标步骤，经 ViewModel 请求匹配推进后执行原导航。通知外部启动等既有导航不伪造用户点击。

“我的 → 使用引导”继续只重看原三页，完成或跳过手动查看都不改四步进度。未修改 AppearanceTransitionHost、navigationReady 的外观交接、圆形主题切换、语言重建或列表恢复策略。未修改 Room 表结构或版本、礼金备份格式、联系人/礼金/提醒业务、按需权限策略；没有新增 Activity、NavHost、依赖、网络或统计功能。
