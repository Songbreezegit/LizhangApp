## 启动窗口交接

旧实现仅在首帧提交后才安装 1500ms 超时，缺 `OnDraw` 或 `FrameCommit` 时无限等待；开始播放后也完全依赖 Compose 帧到达。新实现：

- `StartupWindowGate.attach()` 立即用主线程 Handler 安装 1500ms 窗口截止时间，覆盖内容绘制、首帧提交与系统退出监听缺失。
- 交接就绪后，播放阶段另保留 `900 + 600 = 1500ms` 的截止时间；首个动画帧缺失或后续帧停止时结束覆盖。
- ViewModel 保存绝对单调时钟截止时间，配置重建不延长旧动画；新窗口重新等自己的首帧，保留原有进度。
- 迟到的提交或系统退出回调先核对宿主所有权与截止时间；不能复活已经结束的启动层。
- 正常结束、返回、后台停止、通知直达和配置重建统一清理。注销挂起提交回调和监听器，幂等移除已经转交到 Decor 的公开 `SplashScreenView`；即使系统退出监听尚未交付，也不把系统启动层留在真实内容上方。

超时负责及时放行真实页面，异常路径不强行补播一遍完整动画。主线程 Handler 无法解除主线程本身的持续阻塞；本轮没有设备现场日志或复现结果，因此不能据此保证关闭所有设备上的启动卡顿。

## 功能使用引导

演示直接复用 `ContactsScreen`、`ContactEditorScreen`、`ContactDetailScreen`、`AddGiftScreen`、`GiftRecordDetailScreen` 及其原有 ViewModel，不另画一套练习表单。十二步依次覆盖空联系人列表、空/已填联系人表单、联系人详情、空/已填礼金表单、礼金详情、礼金删除确认、删除后的联系人详情、联系人编辑、联系人删除确认和已清空列表。

用户每次点“下一步”才执行自动填写、保存、跳转或删除；不按计时自动推进。示例为“示例小礼 / 朋友”与“200 元 / 收到 / 生日”。气泡使用原 GlassCard 与主题字体，每步讲清当下功能并显示步骤序号；说明可收起或滚动，操作按钮可换行，随时可退出。底页保留原布局、统计与成功反馈，底页触摸在演示中被拦截，操作统一由下一步推进；删除确认使用原中文文案，并补充仅删除演示内存的说明。

练习控制器依赖领域接口 `GuidePracticeRepository`；导航入口创建独立 `GuidePracticeStore`，只向原页面 ViewModel 注入本次演示的 ContactRepository / GiftRecordRepository。联系人和礼金共用一个不可变快照，关联查询与统计保持一致，专用负数 ID 只在该空间内使用；不调用 Room、真实仓储、文件、Preferences、日志或网络。流程末尾先删除示例礼金，再删除示例联系人；任何有效退出或销毁均先清理子 ViewModel，再清空示例快照。退出由导航目的地核对宿主与单次标记后处理，迟到回调不提前清空其他目的地的状态。每次换页在原页面之后重新注册返回处理，系统返回始终退出整段演示；成功回调核对原 ViewModel 的完成状态与当前步骤。引导完成状态继续使用既有 OnboardingRepository，旧完成偏好兼容，升级用户不被强制重播。

删除确认的气泡、错误与退出按钮放在同一个 GlassDialog 窗口中，不被模态遮罩挡住。每步重新展开说明；折叠说明不隐藏错误。当前页面加载完、删除后的统计或列表更新完，才启用下一步。真实页面子树关闭 SaveableStateRegistry，仅保留当前内存会话状态，避免进程恢复后重新演示时带入旧的保存反馈标记。

App 每步气泡一次 240ms 入场，源码曲线 `(.4, 0, .2, 1)`：透明度 `0 → 1`，竖向位移 `8dp → 0`。页面入场为 260ms、曲线 `(.2, 0, 0, 1)`，透明度 `0 → 1`、横向位移 `24dp → 0`；RTL 调整横向方向。系统关闭动画时直接显示最终状态，不使用永久循环。

[新版 Figma 气泡流程稿](https://www.figma.com/design/4BlDvZZVFb0moftVwiux3f?node-id=31-5610) 根节点为 `31:5610 / guide-automatic-tour`。实际浏览器编辑器已有 24 条轨道、48 个关键帧，气泡在 `0–240ms` 内透明度 `0 → 100`、Y 从基准 `+8 → 0`；浏览器曲线尚未核实，因此 App 源码曲线与浏览器曲线不能视为已完全核对。[旧六场景稿](https://www.figma.com/design/4BlDvZZVFb0moftVwiux3f?node-id=31-694) 的 `31:694` 已标为静态参考，不再是 App 页面依据。

## 导航动效

保留 48dp 浮钮、88dp 导航区、四个 Material 原图标和圆弧凹槽。位置变化以 360ms、`(.2, 0, 0, 1)` 收敛，浮钮与凹槽始终使用同一个位置进度。快速改选从当前位置追随最新目标，不排队，也不重复导航到当前页面。

浮钮轻缩放 `1 → .96（110ms）→ 1（360ms）`；原位图标选中时 120ms 退出，取消选中时 180ms 恢复。浮动图标 160ms 淡入、220ms 从 `.84` 缩放到 `1`，退出 110ms 淡出、120ms 缩放至 `.92`。首次出现直接采用当前目的地，系统关闭动画时直接使用最终状态。

SVG 中的 Material 图标由已安装库源码生成精确路径，不新增资产依赖；App 继续复用同一组 `Icons.Outlined`。
