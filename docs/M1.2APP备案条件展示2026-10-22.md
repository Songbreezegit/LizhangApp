## 唯一配置来源

`release/app-filing.properties` 为 APP 备案展示的唯一配置源，使用 UTF-8；不读取网站 ICP 编号，不从 `release/legal-approval.properties` 或网站文件回填，不在运行时查询备案系统。

当前保持：

```properties
app_filing_status=pending
app_filing_number=
app_filing_developer_confirmed=false
```

- `app_filing_status`：仅接受 `pending` 或 `approved`。
- `app_filing_number`：实际核发的完整 APP 备案编号；不翻译、拼接、替换或推测编号内容。
- `app_filing_developer_confirmed`：本人确认备案已经通过，并已逐字核对核发资料中的编号后才能设为 `true`，不是 Codex 的审批结论。

代码不能证明配置者身份或自动核实备案真实性。确认实际审核通过、编号与核发资料相符，必须由开发者本人完成；本轮未取得或填写真实 APP 备案号，也未将任何状态改为通过。网站备案编号不能代替 APP 备案编号。

## 构建配置与显示条件

Gradle 通过 `providers.fileContents(...).asText` 读取唯一配置源，配置内容作为构建配置输入。只把满足条件的编号写入 `BuildConfig.APP_FILING_NUMBER`；配置原文件、状态和本人确认标记不作为界面内容打包。

| 配置情况 | 源码中的处理 |
| --- | --- |
| `pending`，包括提前填了编号或确认标记的情况 | 生成空的公开编号，关于页面不创建备案卡片或列表项 |
| `approved`、编号非空、本人确认 `true` | 生成经本人确认的原始编号，显示备案卡片 |
| `approved`，但编号为空或未明确确认 | 构建配置阶段拒绝，不产生带假号或占位文案的包 |
| 状态未知、确认标记不是 `true/false`、存在未知字段 | 构建配置阶段拒绝，避免拼写错误被当成批准 |
| 批准的编号含首尾空白或控制字符 | 构建配置阶段拒绝，要求本人核对原始单行编号 |

编号写入 Java 常量前转义引号和反斜杠，保留实际字符；不通过字符串插值改变编号，也不根据编号格式推断审核是否通过。本次不构建 APK，以上是源码逻辑说明。

未改动现有 `verifyOfficialReleaseContent`、正式签名配置或 `verifyReleaseSigning`。新展示配置不授予发布权限，也不会自动更新法律批准或签名身份。原有以下字段仍为 `pending`：

```properties
filing_status=pending
signing_identity_status=pending
signing_certificate_sha256=pending
```

## 关于礼账页面

入口仍为“设置 → 关于礼账”。版本、产品原则和当前能力三个区域及既有简介保留；备案卡片放在其后，沿用现有 GlassCard、24dp 圆角、18dp 内边距、8dp 内容间距及页面 14dp 卡片间距。

批准后显示本地化的“备案信息”、完整 APP 备案号和“前往工信部查询”操作提示。编号不设置最大行数或省略号，允许换行；整张卡片使用现有按压反馈，至少 48dp 触控高度，并有按钮角色和本地化点击说明。查询提示可换行，给外链图标保留空间。

当前公开编号为空，传给信息页的备案内容为 `null`，不创建空列表项；没有假编号、“审核通过后填入”或审核状态文案，也不增加空白区域。显示与否完全依赖安装包内的本地常量，不依赖网络状态。

## 官方查询入口及失败处理

点击卡片中的编号或其他区域，创建 `Intent.ACTION_VIEW`，URI 固定为 `https://beian.miit.gov.cn/`，添加 `CATEGORY_BROWSABLE`，交由系统处理网页链接。

直接调用 `startActivity`，不通过应用包查询判断浏览器是否存在。捕获 `ActivityNotFoundException` 和 `SecurityException`，使用现有 `CenteredSnackbarHost` 显示本地化提示。没有浏览器或系统不允许打开时，相关异常不会直接导致页面崩溃；本轮未在设备上验证该路径。

Manifest 保持原样，未新增 `INTERNET` 或 `<queries>`；没有 WebView、HTTP 客户端、网络 SDK 或后台查询服务。礼账不发起网络请求，网页访问由用户选择的外部应用完成。
