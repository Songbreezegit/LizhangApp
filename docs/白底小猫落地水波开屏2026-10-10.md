# 白底小猫落地水波开屏

日期：2026-10-10。分支：`feat/fresh-ui-icons-privacy`。版本：`1.0.0-rc2 / 23`。

## 最终效果

使用礼账原有的 `launcher_cat.png`，没有另生成或替换猫咪形象。纯白起始，小猫从顶部画面外加速下落，到中心轻压缩、回弹，再触发三道带亮边与柔和阴影的水波。水波向外展开，揭开参考图的白色、奶油黄与淡蓝紫渐变；末尾猫咪淡出，进入原页面。

相比侧面跳入，顶部下落只需一条纵向轨道，既能保留原 Logo 的完整轮廓，也更容易控制落点和回弹。最终播放时长由 900ms 延长为 1300ms；纯白准备等待不计入这段播放时间。

| 时间 | 原生实现 |
| --- | --- |
| 0–380ms | 112dp 原版小猫从顶部外落到画面中心；加速曲线 `(0.45, 0, 1, 1)`。 |
| 380–412ms | 以底部为支点横向增加 6%、纵向压缩 6%，保持落点。 |
| 412–492ms | 恢复比例，向上回弹 12dp。 |
| 492–588ms | 轻落回中心；回弹曲线 `(0.2, 0, 0.2, 1)`。 |
| 380–940ms | 圆形揭示从中心覆盖四角；曲线 `(0.2, 0, 0, 1)`；渐变纹理固定在页面坐标，不随圆形拉伸。 |
| 380 / 470 / 560ms | 三道水波依次发出，每道持续 660ms；波带由 18dp 变为 32dp，透明度逐渐降低。 |
| 940–1300ms | 开屏层淡出，底部页面继续显示同一渐变，避免背景消失。 |

水波使用 Compose Canvas 径向渐变，包含内侧柔影、淡蓝紫或淡粉波体、外侧白色亮边和透明衰减，不依赖 Android 13 的着色器接口。保留 API 26 兼容；API 26 导航栏以暗底浅色系统图标保证可见，API 27 及以上白底使用深色系统图标。

浅色实体按钮继续为 `#FFCEE3`，导航图标为 `#FFCBAE`，其他功能图标为黑色；深色功能图标保持可读的白色。本轮未修改 Room、记账、提醒、备份、隐私正文或其他尚未提交的引导文案。

## 启动交接修复

沿用原 ViewModel 帧时钟与窗口归属门禁，不添加第二套动画计时。首个有效绘制帧到达后，播放截止时间仅补足一次至当前时间加 1900ms，给 1300ms 动画保留 600ms 容错；重建与重复就绪不反复延长。首帧未到或已经超时的情况仍受等待上限约束。窗口旧超时任务检查剩余时间后重新排队，避免迟到首帧被旧期限截断。

Android 16 的系统启动层可能迟到：清理后安装只负责移除系统启动层的无状态监听器，避免迟到副本遮挡页面；原宿主和窗口清理归属检查继续保留。
