2026-10-07，版本 `0.9.5 / 15`，分支 `codex/v0.9.5-navigation-effects`。

## 页面与组件

浅色背景从浅冷灰经过暖灰到轻微暖色，深色改为中性炭灰，减少大面积蓝橘渐变对正文的干扰。主题切换继续使用原有连续色槽插值和圆形过渡。

普通内容卡片使用接近不透明的表面和细描边；输入框与图标按钮使用轻中性底；主按钮使用实色强调，次按钮用较弱的强调底，文字动作保持透明。筛选选中状态保留明显色差。底部导航、保存栏、联系人按钮及菜单继续使用原有 Haze 毛玻璃与外围阴影。

首页年度猫缩为 80dp，与年份入口分开；收礼、送礼金额统一字号与字重，净往来降低层级。快捷入口移除外围及内层重复玻璃卡片，窄屏或大字体改为两列，最近记录使用更轻的分隔和动作。

快捷入口宽度按实际像素扣除间距后向下取整，避免常规四列最后一项因取整误差落到下一行。汇总卡缩小后年份菜单的可见高度也会变小，菜单末端的滚动与惯性余量由自身消费，防止传给首页后意外关闭；正常首页滚动仍关闭菜单。

联系人列表顶部猫移除。“我的”改为 64dp 插图搭配应用名；记一笔、联系人编辑/详情、礼金详情、统计和记录浏览移除顶部装饰。提醒页缩小原有插图，通用空状态使用较小插图及居中文字。沿用透明 PNG，深浅色均无需白底贴片。

修改仅涉及界面布局、颜色、插图使用及必要测试；页面路由、事件处理、数据层、权限时机、Room 结构和备份格式保持兼容。

## 验证

最终源码的 `test`、`lint`、`assembleDebug`、`assembleRelease`、`assembleDebugAndroidTest` 均通过；Debug / Release 各 134 项单元测试，lint 0 错误、41 条警告。134 张最终截图基线比较全部通过，覆盖普通及大字体、深浅色、页面、弹窗、空状态、功能引导和语言选择。

实际查看匹配视口的首页、联系人、记一笔、我的四页调整前后截图，并检查深色首页、深色表单、繁体设置与窄屏大字体法语导航。原始前后截图和四页拼图位于 `build/visual-v095/`；`v0.9.5-页面预览.png` 和 `v0.9.5-页面对比.png` 使用同尺寸页面方便核对。

API 26 / API 36 各 54 项设备回归通过，覆盖导航与功能引导、真实毛玻璃、千条联系人、窄屏大字体、年份菜单末端滚动、键盘避让、保存与重试、圆形外观切换和语言冷启动。两套设备的六次连续语言重建采样均为 0 空屏；SYSTEM 模式显示实际深浅色并正确反向切换。

预览渲染器使用玻璃回退，不能据此确认 GPU 背景模糊；毛玻璃另由实际设备像素检查覆盖 API 26 回退和 API 36 的 Haze 渲染。无障碍语义和按钮回调按已有功能测试核验，本次未做完整无障碍审计。构建、语言资源打包、动画帧及环境限制详见 [导航栏动效验收](导航栏动效0.9.5.md)。
