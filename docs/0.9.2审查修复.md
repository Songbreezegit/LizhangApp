# 0.9.2 代码审查修复

审查基线：`9aa19f1886492d351bc1ad43269f16a4bf200248`。目标分支：`codex/v0.9.2-circular-transitions`。版本保持 `versionName = 0.9.2`、`versionCode = 12`。

## 修复内容

1. **年度提醒编辑**：编辑器、ViewModel、仓库共用领域保存校验，并以仓库中的现有条目区分新建与编辑。新建一次或年度提醒仍要求初始日期晚于今天；已有年度提醒的历史锚点只要能算出未来通知时刻就可继续编辑，停用不影响编辑资格。过期一次提醒和转为一次性提醒仍须选择未来日期。只改名称或启停保留消费日期，防止重复通知。
2. **跨年提前通知**：一次提醒只检查原日期；年度提醒从当前、锚点及已通知日期的最大年份起，有限查找四年内第一个 `triggerAt > now` 且未消费的 occurrence。年末错过次年年初的提前通知时，继续安排后年；保持非闰年二月末、时区和夏令时规则。
3. **外观宿主监听**：布局监听改为成员变量，`detach()` 显式解除注册；重复 `attach()` 或 `detach()` 幂等。语言重建仍保留旧窗口快照，旧宿主清理不再干扰新宿主。圆形展开、颜色预览和语言交接方案不变。
4. **通知日期本地化**：无时区的日期展示统一复用 `DateFormatter`，用于提醒编辑器、卡片、日历及系统通知。通知显式采用应用语言 Context 的 Locale，覆盖中、英、日、韩，ISO 日期仍仅用于原有存储及广播协议。

Room 表结构、数据库版本 2、迁移、礼金备份格式 3、SharedPreferences 存储结构及业务导航均未修改。不合并 main，不发布 Release，不提交构建产物或签名文件。原工作区隐私草案改动保留。
