## 设置页

SettingsGroup 不再接收 title，删除 SectionHeader 和对应 import。确认 settings_data、settings_display、settings_about_group 已无引用后，仅删除这三个资源。

保留三张 GlassCard：
1. 数据备份与恢复、导出 Excel、导出 CSV。
2. 主题设置、深色模式、字体说明。
3. 关于礼账、隐私说明。

卡片间距 16dp，圆角 GlassTokens.Radius = 24dp，横向内边距 16dp。图标、主副标题、Chevron、Switch、Divider、点击回调及 loading 均保持原样。

## 年份菜单

移除 Material DropdownMenu / DropdownMenuItem。新组件 FrostedYearMenu 使用 LazyColumn 和可选择 Row，运行于当前 Compose Window，不创建 Popup 或实体白色 Surface。

HeroSummaryCard 自持独立 yearMenuHazeState。先绘制带 hazeSource 的原汇总卡，随后绘制菜单；菜单不包含在自己的 source 中，不改变底部导航的全局 HazeState。

入口保留普通 Glass、14dp 圆角和原文字/图标，最小触控高度统一为 48dp。卡片与菜单在同一轮 Layout 中先后测量，直接使用入口高度定位，避免依赖全局位置回调造成首帧错位。菜单不增加列表条目高度。

| 项目 | 值 |
|---|---|
| 菜单宽度 | 168dp |
| 入口下方间隔 | 8dp |
| 最大高度 | 240dp，同时不超过汇总卡剩余空间 |
| 每项最小点击高度 | 48dp |
| 菜单圆角 | GlassTokens.ControlRadius = 20dp |
| 背景实现 | Haze 1.6.4，复用 frostedGlassFrame |
| BlurRadius | 20dp |
| 浅色 / 深色 tint | 0.18 / 0.32 |
| 边框 alpha | 0.12 |
| 外围阴影 | 6dp |
| 选中底色 | primaryContainer × 0.12 |
| 展开 / 收起 | 160ms 淡入淡出与轻微纵向展开收起 |

选中年份显示 Check，并提供单选语义。仍使用 state.availableYears、state.year、onYearSelected(year)，未修改统计业务。

关闭行为：
- 选择年份或再次点击入口：关闭。
- 点击页面菜单外区域：关闭，不消费原有页面触摸。
- 返回键：先关闭菜单。
- 首页列表开始滚动或滚动位置改变：关闭。
- 菜单内部滚动：保持展开，支持大量年份。
