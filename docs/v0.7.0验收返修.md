# v0.7.0 验收返修

## 范围

基于 `80109ffaf698ce305d3b9751676d964537ca55c1`，工作区起始干净，fetch 后确认分支 `feat/ui-refresh-v1` 与远端一致。版本保持 `versionName = "0.7.0"`、`versionCode = 7`。

## 间距纠正

真正需要增加的是事件 Chip 第一排与后续排之间的间距。EventTypeSelector 的 FlowRow 增加 `verticalArrangement = Arrangement.spacedBy(10.dp)`，所有换行统一生效，水平方向仍为 8dp。AddGiftScreen 删除包裹事件选择器的 `Box(Modifier.padding(top = 12.dp))`，方向到事件恢复父级 18dp。

截图移除 DirectionSelector 和 30dp Spacer，独立展示事件选择器。普通 412dp 截图形成第一行五个预设、第二行“其他 / 升学宴”；浅色、深色及 1.5 倍字体覆盖自然多行换行。截图使用 AppScaffold 提供正确主题文字颜色。

## 资源与分层

新增资源键：`event_custom_action`、`event_custom_title`、`event_custom_name`、`event_custom_hint`、`event_custom_required`、`event_custom_too_long`、`event_custom_limit`、`action_add`。取消复用 `action_cancel`。

CustomEventDialog 的标题、标签、占位提示、错误、长度提示和按钮，以及 EventTypeSelector 的自定义入口全部读取资源。测试标签不是用户可见文案，保留原标识。

`MAX_CUSTOM_EVENT_NAME_LENGTH = 20` 位于 `domain/model/CustomEventRules.kt`。Dialog 与 GiftEditorViewModel 共用该常量，仍按 trim 后 Unicode code point 数量校验，不改为 UTF-16 String.length。

EventDisplayName 移除中文默认映射，standardName 参数强制由调用方提供。UI mapper `GiftRecord.eventDisplayLabel()` 先在 Compose 上下文读取字符串资源，再调用纯领域规则。Reminder 继续使用 Context 资源映射；CSV / XLSX 使用 `domain/export/EventExportLabels.kt` 内的固定中文导出格式，不引入 Android Context。自定义名称仍优先显示。

Room version 2、MIGRATION_1_2、Backup FORMAT_VERSION 3 与 v1/v2 兼容保持不变；未修改悬浮玻璃参数或保存时序。
