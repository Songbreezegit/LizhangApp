# 多语言扩展与联系人页调整

2026-10-07 完成语言和联系人页调整；随后与导航栏效果一起纳入 `codex/v0.9.5-navigation-effects`，版本为 `0.9.5 / 15`。

## 界面调整

语言扩展阶段移除联系人列表顶部小猫插图，搜索栏成为列表首项；其他插图在该阶段沿用现有设计。随后用户授权调整整体视觉，联系人详情等页面顶部装饰和空状态尺寸按 [视觉层级调整](视觉层级0.9.5.md) 更新。联系人搜索、排序、导入、批量管理和数据库结构未改变。

## 新增语言

语言弹窗和 Android 系统应用语言列表新增繁體中文、Español、Français；跟随系统、简体中文、英文、日文、韩文继续可用。所有语言名称使用固定自称，选择器支持滚动。

| 语言 | 应用标签 | 资源目录 |
| --- | --- | --- |
| 繁体中文 | `zh-Hant` | `values-b+zh+Hant` |
| 西班牙语 | `es` | `values-es` |
| 法语 | `fr` | `values-fr` |

七套源资源各有 344 个资源键：335 个字符串、9 个复数资源。覆盖页面、联系人、礼金、提醒和通知、导出、备份、权限说明、三页首次引导和四步功能引导；西语、法语复数提供 `one/many/other`，覆盖 Android 的百万数量分类。简体中文继续由构建任务生成显式 `values-zh` 副本，繁体资源独立维护。资源打包语言配置同步加入西语和法语。

`AppLanguage` 以 script 优先识别中文：`Hant` 对应繁体、`Hans` 对应简体；未指定 script 时，`TW/HK/MO` 对应繁体，其他中文地区对应简体。构建资源过滤显式保留 `b+zh+Hant`，仅声明 `zh` 会剔除繁体资源；Compose 繁体预览也显式指定 script。语言切换仍由 Android / AppCompat 保存，未增加业务偏好或 Room 字段。外观交接按完整资源语言标签确认简繁已经绘制；日期、月份及金额格式器从同一语言定义选择 Locale，保留地区信息，金额始终使用 CNY。
