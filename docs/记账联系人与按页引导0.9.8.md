# 记账联系人与按页引导（0.9.8）

日期：2026-10-08。版本：`0.9.8 / 18`。分支：`codex/figma-guide-nav-startup`。

## 记账中的联系人

无需预先在联系人页面建档即可打开“记一笔”。联系人区域同时提供选择已有联系人和“新建联系人”入口，选择列表内的新建入口也进入完整联系人编辑页。成功保存后回到原记账页，选择实际返回的联系人编号；金额、日期、收礼/送礼、事件和备注继续保留。取消或放弃新建仅返回原草稿，不替换联系人。保存时同步锁定，避免快速连点新建重复联系人。

联系人仍由领域仓储写入本机 Room；礼金只有用户确认保存后写入。没有新增表、字段、数据库迁移、权限或联网请求，Room 版本和礼金备份格式保持原值。

## 引导顺序

新用户直接进入真实首页，聚焦“记一笔”，随后在真实记账页介绍联系人、金额、收礼/送礼及保存。说明不代填、不自动保存、不自动跨页。其他功能仅在用户第一次打开对应页面时介绍：联系人新增入口、独立提醒、日历、搜索、统计及“我的”备份入口。

各页已读状态独立保存，跳过当前页面不影响以后第一次进入其他页面。升级兼容沿用旧引导完成状态，已完成的升级用户不突然重播。原十二步内存练习保留在“我的 → 使用引导”，作为用户主动选择的回看入口。

参考用户提供的五张竞品截图，采用聚焦区域、半透明遮罩和短气泡；保持礼账已有配色、原控件和本地化。首页删除“年度收支”标题，年份入口与收送金额继续保留。Figma 设计证据见 [按页首次引导 Figma](按页首次引导Figma0.9.8.md)。
