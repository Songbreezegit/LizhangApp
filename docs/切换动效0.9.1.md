# v0.9.1 切换动效

版本：`versionName = 0.9.1`，`versionCode = 11`。

## 范围与方案

仅为语言选择、深浅色开关及主题选择弹窗补充过渡。参考 [Compose 官方淡出淡入示例](https://developer.android.com/develop/ui/compose/animation/composables-modifiers) 和 [GitHub Compose 动效集合](https://github.com/skydoves/compose-animations)，采用克制的 fade-through，不引入第三方动效依赖或更换控件。

`AppearanceTransition` 在原导航树外提供统一过渡：100ms 淡出，执行原设置操作，等待新内容组合后 220ms 淡入，背景色同步缓动。主题弹窗位于独立窗口，使用同一透明度。相同选项不触发动效，过渡期间重复触发不重复提交。

语言依然使用 AppCompat 官方切换和持久化；`rememberSaveable` 只保存淡入标记，在 Activity 重建后接续。初次打开不额外淡入，不保存屏幕图像，不复制导航树。动画使用 Compose 标准时钟，遵循系统动画时长比例，包括关闭动画。

布局、静态颜色、玻璃参数、数据库、备份格式、页面及业务逻辑不变。

## 验证

已通过 `test lint assembleDebug assembleRelease`：Debug、Release 各 92 项单元测试，lint 为 0 错误、20 条既有警告。

API 26、API 36 各通过 5 项设备测试，覆盖初始无淡入、过渡中间帧、重复操作、状态恢复、主题开关和弹窗、四语言切换及重建后页面保留。API 26 关闭系统动画后，3 项语言与主题回归也通过，测试后恢复模拟器设置。
