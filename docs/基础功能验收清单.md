# 基础功能验收清单

## 验收范围

本清单以当前产品决策、`README.md` 和实际代码为准，用于判断礼账的本地单用户基础版本是否完成。

当前产品明确不包含 OCR、图片上传和云端识别。历史 PRD 中的 OCR 目标已经由后续产品决策取消，因此不属于本阶段验收范围，也不得保留隐藏入口、联网权限或令牌。

## 完成标准

每次宣称基础功能完成前，必须同时满足：

1. 不存在业务占位页、空点击入口、OCR 入口、联网权限或令牌。
2. 单元测试、Lint、截图基准、Debug APK 和 Android 测试 APK 全部通过。
3. Pixel 9 全量设备测试全部通过，包含 Room CRUD/搜索/级联、备份恢复、提醒导航和主要界面流程。
4. 最终 Debug APK 可以安装并冷启动到首页。
5. `README.md`、本清单和实际代码一致。
6. 所有修改已经提交 Git，工作区保持干净。

## 非基础版本范围

以下能力需要新的产品决策或真实用户反馈后再进入开发，不影响当前基础版本完成判断：

- OCR、图片上传和云端识别；
- 登录、云同步和家庭共享；
- 农历日期与自定义重复周期；
- 在线服务、会员和 AI 建议；
- 首次 Room 表结构升级及相应迁移。
