# 导航栏与启动调整（0.9.6）

日期：2026-10-08。版本：`0.9.6 / 16`。工作分支：`codex/icon-nav-no-startup`。

本文为当日“纯图标导航、移除旧开屏”的阶段交付记录。用户随后要求使用 Figma 制作新启动动画并接入 App，现已由 [Figma 启动动画](Figma启动动画0.9.6.md) 接替本文的启动部分；纯图标导航保留。下述 APK 和哈希仅对应本阶段，不代表最新动画安装包。

## 本次效果

- 底部四个入口仅显示图标，移除可见的首页、联系人、记一笔和我的标签。
- 普通图标从原来的图标加文字布局改为在玻璃栏主体内垂直居中；选中图标仍位于 48dp 上浮圆钮内，交接位移同步调整为 32dp。保持原有栏高、凹槽、颜色、路由及导航切换动效。
- 图标入口保留完整 Tab 点击范围、选中状态和本地化无障碍名称；去掉文字后不再根据字体大小调整水平间距，RTL 继续使用原有物理坐标映射。
- 功能引导的视觉锚点改为实际可见图标，选中入口使用上浮圆钮；触摸范围与视觉锚点仍分别登记。
- 移除应用内品牌猫、应用名和扩散光环的开屏覆盖层及窗口等待，启动直接显示首页或首次使用引导，不再因品牌动画屏蔽无障碍或延迟功能引导。Android 系统静态启动页保留。

## 修改边界

生产修改仅涉及 `MainActivity.kt` 与 `NotchedBottomNavBar.kt`，不改数据库、备份、权限、通知目标、首次使用引导规则或页面业务逻辑。主题和语言切换、页面出入及按压反馈沿用现有实现。

为保留既有诊断源码引用，`MainActivity.startupState` 继续存在，以 `eligible=false`、`animationsEnabled=false` 初始化；不再接入品牌覆盖层或 `StartupWindowGate`。历史启动动画组件及专用测试文件保留，旧测试中要求出现品牌动画的断言和导航文字截图基线已不对应本次效果，不能用历史通过记录代表当前验收。
