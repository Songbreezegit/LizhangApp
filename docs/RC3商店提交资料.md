## 5. 可复制的权限用途说明

| 权限 | 商店说明 |
| --- | --- |
| `READ_CONTACTS` | 用户主动进入通讯录导入时，用于读取本机有电话号码的联系人候选，进行脱敏预览、筛选和去重。仅在用户授权后读取，预览在内存中处理；确认后将选中的姓名和规范化号码保存为礼账本地联系人，不上传、不修改系统通讯录。拒绝授权仍可手动添加联系人和使用记账等核心功能。 |
| `POST_NOTIFICATIONS` | Android 13 及以上，用户主动启用提醒总开关时申请，用于发送用户自行创建的本地日期提醒。拒绝后不影响联系人和礼金管理，可在系统设置中撤回授权。 |
| `RECEIVE_BOOT_COMPLETED` | 设备重启后重新安排已经启用的本地提醒。只恢复本地提醒调度，不弹出业务页面，不上传数据。此权限为系统广播权限，没有运行时同意弹窗。 |

应用更新、日期、时间和时区变化也会重新核对提醒调度。最终填写以 Release 合并 Manifest 和本轮 APK 检查报告为准；源码 Manifest 当前没有 `INTERNET`、写通讯录、相机、麦克风、定位或广泛存储权限，文件通过 Android 系统文件选择器由用户主动读写。

## 6. 数据处理、第三方 SDK 和本地存储说明

可复制的提交说明：

> 礼账在设备本地处理用户主动输入的联系人、礼金记录及提醒信息。通讯录导入是可选功能，只有主动进入并授权后才读取候选；选中数据在确认后保存为本地联系人。联系人和礼金保存在应用私有 Room 数据库，提醒与设置保存在本地偏好中。没有账号、云同步、广告、分析统计 SDK 或向开发者服务器上传业务数据的功能。
>
> 用户主动导出 CSV / Excel 或创建、恢复备份时，通过系统文件选择器读写指定文件。普通导出和普通专用格式备份不等于加密；密码备份使用 PBKDF2-HMAC-SHA256 和 AES-256-GCM，应用不保存备份密码，开发者无法找回密码。当前账本备份不包含独立提醒与应用设置。系统自动备份禁用。删除应用数据或卸载可能使本地账本丢失，请先主动备份。
>
> 本地通知将提醒标题和日期交给 Android 系统，可能出现在锁屏或通知栏。文档网站由浏览器另行访问，网站服务器日志等处理应以本人批准后的政策说明为准。

当前运行时依赖包括 AndroidX（Compose、Room、AppCompat、Lifecycle、Navigation、Core、Activity）、Kotlin Coroutines 与 Haze 本地视觉库，不把开源 UI / 存储库统称为“没有任何第三方依赖”。没有发现商业广告、统计、账号、云同步 SDK；仍须依据最终 `releaseRuntimeClasspath`、合并 Manifest 和商店隐私检测结果确认。若后台要求第三方 SDK 表，可列“上述本地框架 / UI 库，用于界面、数据库、生命周期和本地视觉处理，无代码配置的业务数据网络上传”，并附最终依赖清单；不得为了填表自行添加 SDK。
