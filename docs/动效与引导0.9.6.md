# v0.9.6 动效与功能引导

版本：`0.9.6 / 16`。

## 目标与参考

本次处理四个问题：缺少开屏动画、导航引导气泡指向不准、组件按压只有灰色覆盖、导航切换生硬。静态页面沿用 [v0.9.5 视觉层级](视觉层级0.9.5.md) 的中性背景与实色内容卡；用户另行要求首页年度收支重新设计并去掉该组件内小猫，调整见下文。透明悬浮玻璃继续用于导航及原有浮层。

实际查看 Uiverse 交互案例后，按手机触屏操作重新设计：

- [JkHuger / moody-crab-18](https://uiverse.io/JkHuger/moody-crab-18)：用于开屏节奏与扩散动效参考。
- [KINGFRESS / purple-kangaroo-17](https://uiverse.io/KINGFRESS/purple-kangaroo-17)：用于主题色扩散与按压反馈参考。
- [SelfMadeSystem / selfish-starfish-40](https://uiverse.io/SelfMadeSystem/selfish-starfish-40)：用于按钮强调与连续反馈参考。
- [ayman-ashine / curvy-starfish-3](https://uiverse.io/ayman-ashine/curvy-starfish-3)：用于提示气泡及指向关系参考。

参考只用于动效与视觉组织。实现为本项目原创 Compose 代码，未复制网页代码、图片或素材；品牌猫继续使用项目已有透明资源，不新增远程图片、网络依赖或加载请求。

## 一次冷启动品牌动画

首次从桌面冷启动时显示品牌猫、应用名和单次扩散光环。猫先轻微上移放大，再回落到正常尺寸；应用名稍后出现，覆盖层逐渐淡出，下方真实首页或首次使用引导同步准备。

当前源码以 `StartupAnimationViewModel.DURATION_MILLIS` 为唯一总时长来源，值为 **880ms**。猫在前 300ms 入场、随后 180ms 收敛；应用名从 110ms 开始出现；光环在前 740ms 扩散，覆盖层从 560ms 开始淡出。品牌图标为 112dp，扩散区域为 208dp；系统静态图标通过独立留白接近入场时约 85dp 的大小，减少交接尺寸跳变。后续调参须同步更新本文，不以初稿参数替代最终代码。

计时从当前窗口首帧实际提交、且 Android 12 及以上系统启动层移除后开始，避免动画在不可见的系统启动层背后播放完。旧系统使用绘制完成后的回调；系统退出回调缺失时设有超时兜底，直接进入真实页面。逐帧进度只在图层和 Canvas 绘制阶段读取，避免冷启动时反复重组整个品牌层。

Android 13 及以上显式设置 `windowSplashScreenBehavior=icon_preferred`。按 [Android 启动屏说明](https://developer.android.com/develop/ui/views/launch/splash-screen)，部分启动来源默认可以只显示底色；真实设备采样发现了这一交接空帧，因此明确保留系统品牌图标，随后交给应用内动画。

播放机会只保存在进程内，不新增用户偏好、启动页面或返回栈条目。配置重建继续当前进度；系统状态恢复、通知直达、同进程再次打开不补播。应用进入后台或收到提醒直达时结束覆盖，返回键也可立即结束。系统关闭动画时跳过品牌动画。

覆盖期间不把触摸或无障碍焦点交给下方尚未完整显示的业务控件；功能引导等开屏结束后再显示。首次使用引导、已有用户跳过引导、权限请求时机和通知导航仍沿用现有业务规则。

## 真实视觉锚点与气泡箭头

功能引导把“可点击范围”和“视觉锚点”分开登记。底部导航的点击范围仍保留足够的触控空间，边框只围绕图标和标签的实际可见区域，避免把顶部空白一起框入。

高亮边框从本帧布局坐标计算，并向外留 4dp 间距。气泡在兄弟控件完成放置后，以当前锚点和底栏位置进行子组合与测量，避免首次布局使用过大的旧高度而消失；说明区可以滚动，操作区保留在可见范围。气泡在安全区域中选择目标上方或下方；箭头根部受气泡圆角与屏幕边缘约束，尖端始终落在目标相邻边的中心。物理坐标只转换一次，支持 RTL、不同系统栏高度、窄屏和大字体。

目标未布局、离场或只剩部分可见时不保留过期气泡。注册使用组件实例所有权，旧导航组件销毁时不会清除新组件已经登记的位置。高亮层不接管目标控件点击，跳过与下一步仍由原有引导状态控制。

## 主题触点光晕与轻压回弹

公共按压层使用 `MutableInteractionSource` 和标准 `clickable`、`selectable`、`toggleable`，由真实按下位置产生主题色光晕，同时轻微缩放并绘制细轮廓。按下约 90ms 收紧；松开采用克制弹簧回弹，光晕约 180ms 消退。列表项缩放幅度小于按钮与图标入口，不改变布局尺寸。

已接入公共按钮、文字按钮、图标按钮、筛选项、可点击卡片、联系人浮动菜单，以及列表行、设置项、年份和语言选择、日历日期、表单选择、保存栏与反馈条操作。开关和复选框保留原生选中动画，公共包装层替换其默认灰色 ripple。开关只叠加光晕和轮廓，保持可拖动控件的触摸坐标固定，避免缩放参与手势仲裁；新增嵌套设置行内八次连续真实点按检查。

滚动、拖出或取消手势仍由 Foundation 仲裁，取消后回位且不触发点击；禁用和保存中不产生可用按压反馈。键盘焦点显示主题色轮廓，键盘确认仍使用标准点击语义。遮罩关闭区域保持无视觉反馈，危险操作继续使用原有危险色。普通静止表面、文字层级与玻璃透明度不因按压系统而改变。

## 连续导航与页面出入

底栏仍保留透明悬浮玻璃、四个固定入口、真实 U 形凹槽和原有路由。浮钮与凹槽共享同一个位置进度，使用阻尼比 `.86`、刚度 `300` 的弹簧移动；快速改选时从当前运动状态继续，不先跳回起点。

选中图标随浮钮一起移动，交接时短暂缩放和淡入淡出，原位图标同步淡出；移动过程中浮钮内始终有图标内容。首次显示直接位于当前目的地，重复点击当前入口不重复导航。

页面切换增加短距离水平移动和透明度过渡，主入口顺序与返回方向决定运动方向。当前进入位移为页面宽度的 1/8、360ms，退出位移为 1/12、260ms；透明度分别使用 240ms 和 220ms。底栏出现时轻微上移并淡入，进入记一笔、详情或联系人管理等原本隐藏底栏的页面时轻落淡出，退出阶段仍保留最后有效入口状态。

动画不延迟业务导航回调，也不改写返回栈、保存状态、表单业务或通知目标。RTL、大字体、连续改选及系统关闭动画时的落点需要通过实际运行验证，不能只依据动画参数推断。

## 首页年度收支重排

依据用户追加要求，年度汇总卡移除 `home_hero_cat` 插图。延续先前实际查看的 [Noah 记账 UI 参考](https://www.xiaohongshu.com/explore/6a02fedb000000003502cdc7) 中的中性底与清楚金额层级，顶部收拢为年份选择和较轻的“年度收支”标题；收礼、送礼金额采用同字号、同字重的对等双列，底部净往来保持较弱层级。没有增加嵌套玻璃卡片或新装饰图。

布局先测量完整金额与本地化标签。窄屏、大字体或任一金额放不下半列时，两组金额整体改为上下排列，不省略数字；极长金额仍可在完整宽度内自然换行。“年度收支”新增七种语言文案。年份入口保留原点击与选择回调，菜单继续使用真实入口测量高度加内边距定位；原有玻璃、外部点击关闭和菜单末端滚动处理继续沿用。

新增五张首页预览覆盖普通双列、深色、320dp 长金额、法语与繁体大字体；已逐张检查实际渲染图。年度卡片内移除小猫，最近往来为空时的辅助插图继续保留。

## 变更边界

- 保留 `ui → ViewModel → domain.repository ← data` 分层，不改 Room 表结构、备份格式、联系人处理规则或权限时机。
- 不恢复 OCR、图片上传或云端识别，不记录联系人、金额或备份隐私数据。
- 沿用七种语言资源与 v0.9.5 页面层级，品牌动画文字读取现有本地资源。
- 动画取样只使用测试按钮、测试联系人和独立测试设备，不把用户真实页面数据纳入截图或日志。
- 预览渲染器不能证明真实 GPU 毛玻璃效果；最终验收须结合设备截图和实际中间帧。
