# 图标和截图规格

核验日期：2026-10-10。下表区分官方公开硬性要求与项目制作建议；具体证据和未访问后台的范围见 [官方规则来源](07-官方规则来源.md)。

## 官方公开要求

| 平台 | 图标 | 功能截图 |
| --- | --- | --- |
| vivo | 256×256 或 512×512；直角，500KB 以内，清晰且与安装后图标一致 | 3–5 张；1080×1920；JPG / PNG；2MB 以内；同一方向，内容清晰、完整且不重复 |
| OPPO | 512×512；PNG；小于 1MB；直角，与包内图标一致 | 竖版 3–5 张；1080×1920；JPG / PNG；每张小于 1MB；内容与实际应用相符，不能出现其他品牌标识 |

vivo 依据 2026-09-23 官方审核规范 2.7 / 2.8；OPPO 依据目前公开可读的 2024-08-28 官方上传指引。OPPO 登录后后台规则版本及校验本轮未核验，提交时须重新核对。OPPO 横版为选填且公开表格尺寸表述易混淆，本方案使用竖版，不推断横版规格。

## 共用制作建议

采用 512×512 直角 PNG 图标 ≤500KB；制作 5 张 1080×1920 竖版 JPG / PNG，单张 <1MB。共用规格是本项目为同时满足已读公开限制而选定的建议，不是两商店联合发布的要求。

保持已验收图标和 UI 视觉；不添加排名、官方 / 首发角标、其他商店标识、手机品牌外框或未实现能力。截图从最终包实际运行画面取得，使用虚构数据。不将 Figma 稿、AI 生图或拼造界面标为实机截图。若设备原始画面比例不同，优先在适合目标比例的测试设备上拍摄；需要放入宣传画布时保持 UI 比例、文字可读和内容完整，最终以后台审核要求确认，不拉伸页面。
