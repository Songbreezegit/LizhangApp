## 产品内容核对依据

- `app/src/main/AndroidManifest.xml`：当前三个显式权限、无 INTERNET、禁用自动备份及本地提醒广播。
- `app/build.gradle.kts`：候选版本、正式独立入口、API 范围和运行时依赖。
- `app/src/main/assets/legal/privacy.md`、`terms.md`、`help.md`：数据范围、文件导出、备份限制、联系人删除影响、独立提醒及离线文档。
- `website/site.config.json` 与 App 法律链接配置：预期正式域名和路径，待备案状态。
- 既有 RC3 商店资料仅作为目录整理的起点，本轮重新读取公开规则并核对当前代码，不把旧设备或线上结果当成本轮验收。

本目录没有修改 UI、900ms 启动动画、CSV 防护、数据库结构或备份格式；它不是设备测试证据。
