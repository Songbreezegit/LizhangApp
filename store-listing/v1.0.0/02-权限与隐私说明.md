# 权限用途与隐私数据处理

用于 vivo / OPPO 权限说明、隐私问卷和审核补充。源码依据 `app/src/main/AndroidManifest.xml`、`app/build.gradle.kts`、`app/src/main/assets/legal/{privacy,terms,help}.md`。最终填表以正式 APK 的合并 Manifest、依赖和检测结果为准。

## 权限用途

| 权限 | 可复制用途说明 |
| --- | --- |
| `android.permission.READ_CONTACTS` | 仅在用户主动进入通讯录导入并授权后，读取本机有电话号码的联系人候选，进行脱敏预览、筛选和去重。预览在内存中处理；确认后仅把选中的姓名和规范化号码保存为礼账本地联系人。不上传、不修改系统通讯录。拒绝仍可手动添加联系人和使用记账核心功能。 |
| `android.permission.POST_NOTIFICATIONS` | Android 13 及以上在用户主动启用提醒时申请，用于发送用户自行创建的本地日期提醒。拒绝不会阻止联系人、礼金、备份和导出，可在系统设置中撤回授权。 |
| `android.permission.RECEIVE_BOOT_COMPLETED` | 设备重启后重新安排已启用的本地提醒。只恢复本地提醒调度，不弹出业务页面，不上传数据；没有运行时授权弹窗。 |

更新应用、日期、时间和时区变化时也会核对提醒调度。最终合并 Manifest 可能包含 AndroidX 生成的自定义内部广播权限，应以 APK 报告逐项解释；不要把它当作通讯录、联网或其他运行时敏感权限。

当前源码 Manifest 没有 INTERNET、相机、麦克风、定位、写通讯录、广泛存储或精确闹钟权限。文件读写由用户主动通过 Android 系统文件选择器选择目标。官方网页由用户点击后交给系统浏览器访问，网页联网行为与礼账本地记账分别说明。

## 可复制的数据说明

礼账在设备本地处理用户主动输入的联系人、礼金与独立提醒。联系人和礼金记录保存在应用私有 Room 数据库，提醒和设置保存在本地偏好中。通讯录导入是可选功能，未确认候选只在内存预览，只有用户选中并确认的姓名和号码会保存为礼账联系人。

应用没有账号、云同步、广告或商业分析 SDK，也没有向开发者服务器上传账本的功能。当前数据库没有礼账自身的密码加密，依赖操作系统应用隔离和用户的设备保护。

用户主动导出 CSV / Excel 或创建、恢复备份时，通过系统文件选择器读写指定文件。普通备份、CSV 和 Excel 没有礼账密码加密。密码备份采用 PBKDF2-HMAC-SHA256 与 AES-256-GCM，应用不保存密码，开发者无法找回密码。选择第三方云盘位置时，该文件服务会按自身规则处理文件。

账本备份包含联系人和礼金记录，不包含独立提醒、主题、语言、提醒设置或引导进度。恢复会替换现有联系人与礼金记录，不是增量合并。删除联系人会同时删除其关联礼金，不修改系统通讯录；独立提醒需单独删除。系统自动备份已禁用，卸载或清除应用数据可能导致本地数据丢失。

本地通知会将提醒标题和日期交给 Android，可能显示在锁屏或通知栏。公开文档网站的服务器请求信息与日志应以本人批准的最终政策为准；本轮没有验证线上日志配置。

## 依赖及后台问卷

当前运行时依赖包括 AndroidX（Compose、Room、AppCompat、Core、Lifecycle、Navigation、Activity）、Kotlin Coroutines 与 Haze 本地视觉库。没有发现广告、分析、账号或云同步 SDK。不得把本地框架依赖宣传成“没有任何第三方依赖”。后台若要求 SDK 名单，按最终 `releaseRuntimeClasspath` 逐项列出名称、版本、本地用途和实际数据处理，不能为了填表自行新增 SDK。

若商店问卷询问数据收集、共享、加密或删除，应遵循该问卷术语，说明本地处理和外部文件服务选择；不要把本地存储直接填成所有字段“无”。通讯录用途截图、通知用途截图需要本人使用虚构数据在最终包中截取，本轮未制作。
