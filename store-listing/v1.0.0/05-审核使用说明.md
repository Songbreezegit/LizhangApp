# 审核人员使用说明

以下文字仅在正式政策、备案或平台认可材料、签名、versionCode 和最终安装包通过检查后使用。RC4 不直接提交。包名 `com.yangsong.lizhang`，正式版本 `1.0.0`，无需注册登录或测试账号。

## 可复制的审核补充说明

礼账是一款本地人情礼金往来记录工具，无注册登录流程，不需要测试账号。核心功能可离线使用。首次打开可离线阅读完整隐私政策和用户协议，两份正文加载成功后才能主动明确确认；拒绝可返回告知或退出，加载失败可重试或退出。首次隐私告知不会申请通讯录或通知权限。

完成告知后可手动建立虚构测试联系人，从“记一笔”保存收礼或送礼记录，再查看联系人往来、搜索、统计及日历。通讯录导入是可选功能，拒绝授权后仍可手动添加；本地日期提醒独立创建，拒绝通知权限不影响记账。

请使用虚构数据测试导出与备份。CSV / Excel 用于查看和整理，不能通过礼账备份恢复入口导入。备份恢复前有校验和摘要确认，恢复会替换当前联系人与礼金记录；独立提醒和设置不在账本备份内。应用不提供账号、云同步或开发者服务器恢复。

## 推荐走查顺序

1. 安装最终正式包，阅读隐私告知，打开两份离线全文；先检查拒绝可返回或退出，再重新进入明确确认。完整法律正文当前为中文，其他界面语言有回退说明。
2. 在“记一笔”表单新增虚构联系人，保存后回到表单，选择联系人并录入一笔今天或过去日期的收礼 / 送礼；记录页面支持现有编辑和删除。
3. 查看首页、搜索、联系人详情、统计和日历。只使用虚构联系人与虚构金额。
4. 从联系人页右下角新增菜单进入通讯录导入，检查用途告知；可拒绝后返回手动添加。若需验证授权，使用仅含虚构联系人数据的测试设备，不读取真实通讯录。
5. 从首页右上角铃铛进入独立提醒，新增未来日期的提醒并可选每年重复；按需开启总开关及通知权限。系统和省电设置可能影响实际送达。
6. 在“我的”中导出 CSV / Excel，创建普通与密码备份；测试恢复时先阅读摘要再确认替换，密码至少 8 字符。请在独立测试环境保存测试文件。
7. 在“我的”中离线查看隐私政策、用户协议与帮助文档。官方网站链接只有主动点击后由系统浏览器联网打开。
