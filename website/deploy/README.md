# 礼账官网部署与回滚

官网沿用现有 ECS / Nginx 静态站点。当前生产源码为 `3ed322bac7083ea345fb63944568e39066fd6824`，发布详情见 [v1.0.0 交付记录](../../docs/v1.0.0-public-release-handover.md)。

## 目录

| 位置 | 用途 |
| --- | --- |
| `website/dist-production/` | 本地生产静态文件 |
| `build/website-production-*/` | 本地构建记录 |
| `/var/www/lizhang-privacy/releases/` | 服务器版本目录 |
| `/var/www/lizhang-privacy/current` | 当前版本的符号链接 |
| `/var/backups/ecs-ops/` | 发布、配置备份及回滚记录 |

公开目录由 root 管理，目录权限为 0755、文件为 0644，Nginx 只读。

## 发布步骤

1. 使用现有生产构建，核对网站批准摘要和逐文件清单。
2. 通过既有管理连接将文件放入 adminuser 的私人暂存目录，比较传输前后的大小和 SHA-256。
3. 创建新版本目录，核对类型、权限、清单和摘要。复用旧版文件时，也核对其摘要。
4. 保存旧版及回滚入口，再原子切换 `current`。仅切换静态文件时无需重载 Nginx。
5. 从公网检查页面、安全响应头、内部文件隔离和真实 APK 下载。

当前公开产物共 12 个文件，包含六个页面、404、robots、两张品牌图片、CSS 和下载页脚本。构建记录、审批源文件、源代码和部署脚本保存在公开目录之外。

## Nginx

已有 HTTPS、HTTP 跳转和回环模板位于本目录。TLS、证书位置、域名及站点结构沿用现有配置。

仅 `/download/` 允许 `script-src 'self'`，用于复制摘要；其他页面继续使用原策略。下载页保留 `nosniff`、`DENY`、`no-referrer`，内部文件和敏感后缀仍由原规则拦截。该最小调整已由本人明确授权，并于 2026-11-04 通过实际配置检查和重载。
