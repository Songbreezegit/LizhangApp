礼账官网 v1.1 Windows 本地审核预览

本包对应移动端视觉与阅读体验优化，尚未测试，不是线上生产网站。
保留现有品牌与法律正文。正式法律批准、生效日期和日志事实沿用基线；
本轮视觉改动必须在用户验收后另行批准新的网站输入摘要，才可安排生产发布。
本包保留审核横幅、noindex 和禁止抓取，不能直接上传公网。

Windows 启动步骤：
1. 本机须已安装 Node.js 18 或以上。本包不内置或自动安装 Node.js，无 npm 依赖。
2. 完整解压 ZIP，保留 START-PREVIEW.cmd、scripts 和 dist 的相对位置。
3. 双击 START-PREVIEW.cmd，并保持窗口打开。
4. 等待显示“服务已启动”，再在同一台 Windows 电脑的浏览器打开终端显示的地址。
5. 按 Ctrl+C 停止服务；停止服务或关闭窗口后，地址不可继续访问。

也可在解压目录打开 PowerShell，执行：
node scripts/preview.mjs

默认端口 4173。仅在启动成功后，地址才为 http://127.0.0.1:4173/。
若端口占用，不结束未知进程；改用 node scripts/preview.mjs 4174，
或在命令提示符执行 START-PREVIEW.cmd 4174。

仅监听 127.0.0.1，不开放公网，不请求防火墙放行，不自动打开浏览器，
不修改 DNS、ECS、Nginx 或现有正式站点。
127.0.0.1 代表打开浏览器的电脑，不能在另一台手机直接访问此回环地址。
不要直接双击 dist 中的 HTML，页面使用站内绝对路径，须通过本地服务打开。
ERR_CONNECTION_REFUSED 通常表示本机对应服务没有启动或连接被阻止，
请先查看启动窗口提示。本次交付未启动服务，也未访问上述地址。

本轮调整供用户自行审阅：
- 首页功能卡在手机单列、平板两列、宽桌面四列，说明自然换行。
- 隐私政策、用户协议和帮助在小屏默认收起目录；展开后单列，大屏保留侧栏。
- 顶部导航在宽度不足时水平滚动，当前页有明确选中态。
- 小猫插画采用容器自适应尺寸，保留原图与比例。
- 备份风险提示、三个法律与联系入口、页脚排版统一。
- 联系页保留邮箱、反馈要素、隐私请求及不要发送隐私数据的提醒。

本包没有加入 App 截图展示。后续需用户提供脱敏且允许公开的真实截图。
本会话没有此前五张实机截图，实施依据为任务说明。

dist 包含全部生成页面、CSS、原品牌图片、robots 和审核构建信息。
不包含 Android 源码、原始法律模板、签名文件、凭据或 Node.js 运行时。

本轮仅完成源码修改与审核包构建，没有执行任何测试、Lint、浏览器验证、
实机验证或生产部署。全部测试和最终验收由用户本人进行。
