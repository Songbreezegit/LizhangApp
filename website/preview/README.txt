礼账官网本机审核预览

本包是未测试的本地审核产物，不是已上线的公网官网。
本次交付没有替你启动任何预览服务，也没有提供已验证可访问的平台网页入口。

启动顺序（Windows）：
1. 安装 Node.js 18 或以上版本。
2. 完整解压 ZIP，保留 START-PREVIEW.cmd、scripts 和 dist 的相对位置。
3. 双击 START-PREVIEW.cmd，并保持窗口打开。
4. 等待终端显示“服务已启动”后，再在同一台 Windows 电脑上打开终端显示的地址。
5. 按 Ctrl+C 停止服务；服务停止或窗口关闭后，浏览器将无法继续连接。

也可在解压目录打开 PowerShell，执行：
node scripts/preview.mjs

默认端口 4173。若提示端口已被占用，先确认已有服务归属，不结束未知进程；改用：
node scripts/preview.mjs 4174
或在命令提示符执行 START-PREVIEW.cmd 4174。

仅启动成功后，默认地址才是 http://127.0.0.1:4173/。
127.0.0.1 始终代表打开浏览器的这台电脑；远程执行器上的回环地址不能代替你的 Windows 地址。
出现 ERR_CONNECTION_REFUSED 通常表示该电脑对应端口没有正在监听的服务，或连接被阻止；先看启动窗口的实际提示，不代表公网官网已发生故障。
本脚本只监听 127.0.0.1，不开放公网、不请求防火墙放行、不修改 DNS/ECS，也不会自动打开浏览器。
不要直接双击 dist 内的 HTML，站内绝对路径需要本机 HTTP 服务。

dist 是完整生成的静态网页、CSS、品牌图片、robots 和构建信息。
页面保留审核状态及禁止收录；不能重命名或直接上传成为生产官网。
隐私正文、生效日期、生产批准、服务器日志及接入条件仍以仓库中的发布门禁为准。
本包不包含 Android 源码、原始法律模板、签名文件或凭据。

未测试，等待用户本人验收。未执行浏览器、HTTP、性能或线上验证。
