## 使用的 Skill 与设计决策

优先采用已安装的 `frontend-design`，未安装、更新或覆盖 Skill。设计方向是保持礼账温和的生活气息，减少内容被挤窄与无效留白，让小猫继续成为主要品牌识别元素。

调色板沿用正文墨色 `#292e35`、次要文字 `#4d545f`、浅蓝主题的文字色 `#355d96`、杏橘 `#ffc8ae`、奶白背景 `#fffaf0` 和浅蓝背景 `#edf2fc`。保留原有渐变及半透明卡片，不新增装饰、动画或外部字体。

设计前的两种组织方式：

```text
手机：品牌 → 横向导航 → 标题与说明 → 主次按钮 → 信任标签 → 小猫
      → 单列功能卡 → 备份说明与风险 → 三个文档入口 → 页脚

桌面：品牌与导航同排 → 文字 / 小猫并排 → 四列功能卡
      → 备份说明 / 帮助链接 → 文档说明 / 三个入口 → 页脚

手机文档：页面标题 → [本页目录 · 点击展开] → 完整正文 → 相关入口
桌面文档：页面标题 → 左侧目录 / 右侧正文 → 相关入口
```

对照任务复核后保留既有卡片、编号、渐变与主标题配色，因为这些均来自用户明确的品牌及组件要求。没有另加字体、标签、图标、背景或截图占位。内容左对齐，不采用两端对齐或额外字距。

## 排版与响应式规范

| 项目 | 默认根字号 16px 时的规则 |
| --- | --- |
| 字体 | 本地苹方 / 冬青黑体 / 微软雅黑 / 思源黑体与 Noto 中文字体，随后回退系统无衬线 |
| 通用正文 | 16px，行高 1.72，正常字距 |
| 功能说明 | 15px，行高 1.72 |
| 功能标题 | 19px，行高 1.4 |
| 手机主标题 | 28–34px，行高 1.4 |
| 辅助标签 | 13px；审核横幅为 12px |
| 手机法律正文 | 15.5px，行高 1.75，段距 14px |
| 法律章节标题 | 手机 21px，平板及桌面 22px，行高 1.5 |
| 常用触控入口 | 导航及目录至少 44px 高，主要按钮至少 48px 高 |
| 卡片 | 统一 20px 圆角及既有边框；内容决定高度 |
| 手机页边距 | 16px，法律卡片内横向留白 16px |

上述样式以 rem 为主，不固定根字号，不设置字体缩放、不禁用浏览器缩放。长链接允许换行，文档列表使用自然缩进；表格保留原生独立横向滚动容器及键盘焦点。

- 小于 48rem（默认 768px）：功能卡单列，Hero 纵向排列。
- 48rem 起：功能卡两列，Hero 文字和小猫并排。
- 64rem（默认 1024px）起：导航和品牌同排，文档启用 14rem 左侧 sticky 目录，正文占剩余宽度。
- 68.75rem（默认 1100px）起：功能卡四列。

目录在小于 64rem 时采用不带 open 属性的原生 details / summary，展开后为单列。桌面导航和小屏目录由同一份渲染结果生成链接，CSS 互斥显示；未修改 Markdown 解析器、章节生成规则或正文 ID。大屏目录限制在视口高度内并允许自身滚动。
